# SubCurrent — Mark System v1

歪んだリングから派生させたマーク・ロックアップ・ステッカー一式。
プレビュー（全案の並びと実寸テスト）はアートボードのページを参照。

## 中身

```
marks/      マーク15案
  m-A1〜A8  歪んだリング ファミリー（推し方向）
  m-B1〜H1  その他のサイケ層（フライヤー背景・VJ・グッズ用）
lockups/    ワードマークとの組み 3案
  lockup-1-horizontal   横組み（Web・名刺・署名の標準形）
  lockup-2-sonar-c      Cから波紋が広がる（原案B の発展形）
  lockup-3-stack        縦組み
stickers/   ステッカー 10案（Sub / Current 縦積み）
  sticker-1〜7          camel case 版
  sticker-*-CAPS        SUB / CURRENT 大文字版
```

## 全部が同じ式から出ている

```
r(θ) = R (1 + a₃·sin(3θ + φ₃) + a₅·sin(5θ + φ₅))
```

「円が低音の波面で曲げられている」という一行の理屈だけで、
A1〜A8 は振幅・線の太さ・見せる範囲を変えているだけです。
だから並べても family に見え、あとから増やしても崩れません。

## Illustrator での扱い

- SVG を開くと**すべてパス**。文字もアウトライン化済み（フォント環境に依存しない）
- リングは Catmull-Rom → 3次ベジェ変換済み。**アンカー72点**なので手で歪ませ直せます
- ワードマークは **Inter** ベース。最終フォントを変えるならここだけ組み直す
- 色は黒地 `#04070B` / 白 `#FFFFFF` / ソナー青 `#4FC3D9` / 土 `#A8825A`

## ステッカー入稿

- 塗り足し **3mm**、文字は仕上がりから **3mm 以上**内側に
- カラーモードは **CMYK**。黒は K100 ではなく**リッチブラック**（C40 M30 Y30 K100）
- `sticker-3-diecut-ring` は輪郭パスを**カットラインとして別レイヤー**に（スポットカラー指定）
- `sticker-7-mono-1color` は1色版。白い部分は**紙の地**になります

## 実寸の目安

| | 60mm | 40mm | 25mm |
|---|:--:|:--:|:--:|
| sticker-3 ダイカット | ◎ | ◎ | ○ |
| sticker-5 単環 | ◎ | ◎ | ◎ |
| sticker-1 リング背景 | ◎ | ○ | × |

**まず1種類作るなら sticker-3 を60mm。** 輪郭そのものが歪んだリングなので、
貼られた状態で最も「これは SubCurrent だ」と分かります。
