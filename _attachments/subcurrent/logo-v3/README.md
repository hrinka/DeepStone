## T5 / T6 をどう直したか

**T5 → U8** — 角丸の箱にスピーカーが並ぶと、どうしてもガジェットのアイコンに見える。
下端を尖らせて護符（タリスマン）の形にし、彫版のリングと月に差し替えた。

**T6 → U7** — 文字が絵の真ん中に浮いていた。下1/3に落として地の帯を敷き、
上を密なモアレ場に。文字が座る場所ができ、上半分は思い切り揺らせる。

## ポップさを抜く4つの手

1. **角丸をやめる** — 護符・盾・不定形の輪郭にする
2. **ハッチングを入れる** — 線の密度で明暗を作ると手の跡が出る
3. **不揃いにする** — 光条・年輪・石の間隔を揃えない
4. **意味ありげな線を足す** — 至点のアライメント、月相、目盛り

## 色

- 黒 `#04070B` / 白 `#FFFFFF`
- **土 `#A8825A`**（v3 のアクセント。CMYK 概ね C35 M45 Y70 K10）
- 青 `#4FC3D9`（水寄りに振る回だけ使う）

## 入稿

- 塗り足し **3mm**、文字は仕上がりから **3mm 以上**内側に
- **CMYK**。黒は K100 ではなくリッチブラック（C40 M30 Y30 K100）
- `u-3` `u-8` は輪郭パスを**カットラインとして別レイヤー**に
- `u-9` は1色版。白い部分は**紙の地**になります

## 実寸

円環に文字を回した印（U1・U2・U9）は **40mm 以上**。
**25mm で生き残るのは U3 と U7** のみ。
