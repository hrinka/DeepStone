# POST-50 リサーチメモ — ベルガモット精油

## 基本情報
- 学名: Citrus bergamia
- 科: ミカン科（Rutaceae）
- 抽出部位: 果皮（冷圧搾法）
- 産地: イタリア・カラブリア州（世界生産量の約95%）
- 抽出量: 果皮約200個で精油1本分（約10ml）

## 名前の由来
- トルコ語「beg armudi（ベグ・アルムディ）」= 「梨の王」または「梨の玉」
- 果実のヘタ部分がやや出っぱった洋梨形から命名、という説
- イタリアの都市名「Bergamo（ベルガモ）」に由来する説もあり（諸説あり）

## 植物的背景
- ビターオレンジ（ダイダイ）× レモン/ライムの自然交配とされるが原種は未解明
- カラブリア州以外では同じ香りが出ない（土壌・気候・日照の組み合わせ）
- 果実は苦くて食べられない → 皮の精油が唯一の産物

## 歴史タイムライン
| 年代 | 出来事 |
|------|--------|
| 1650年頃 | カラブリア州に最初のベルガモット農場 |
| 17世紀 | オーデコロン「ケルンの水（Eau de Cologne）」の主成分として使用 |
| ナポレオン時代 | 毎日大量のオーデコロンを使用（ナポレオンの最愛の香り） |
| 19世紀初頭 | アールグレイ紅茶の香り付けとして定着 |
| 現代 | 高級香水・アロマセラピー・フードフレーバーとして世界展開 |

## アールグレイとの関係
- チャールズ・グレイ伯爵（英国第2代グレイ伯爵・首相）が1830年代に中国の外交使節から贈られたブレンド、とも。
- 紅茶にベルガモット精油（またはエキス）を少量加えたフレーバードティー。
- 現在も英国ティーカルチャーの象徴として世界的に愛飲される。

## 化学成分
| 成分 | 割合（概算） | 作用 |
|------|-------------|------|
| リモネン（d-Limonene） | 30〜40% | 気分高揚・抗菌 |
| 酢酸リナリル（Linalyl acetate） | 17〜31% | 鎮静・鎮痛 |
| リナロール（Linalool） | 9〜11% | GABA活性・抗不安 |
| γ-テルピネン | 約8% | 抗酸化 |
| β-ピネン | 約7% | リフレッシュ |

## 科学的根拠
- **リナロール**: GABA-A受容体に結合。海馬でのGABA量を最大50%増加させることが動物実験で報告。ラベンダーと同様のメカニズム。
- **2017年 Pilot Study（PMC5434918）**: 精神科待合室でのベルガモット吸入実験 → 気分の有意な改善（Positive Feelings）を確認。
- **特異な逆説効果**: リモネン（高揚）とリナロール・酢酸リナリル（鎮静）が共存 → 「落ち着くのに気分が上がる」唯一性。

## 光感作性（重要）
- フロクマリン類（特にベルガプテン）を含むため、皮膚に塗布後に日光に当たると色素沈着のリスク。
- フロクマリンフリー（FCF）タイプは光感作性なし。
- 安全な使用法：ディフューザー・室内芳香浴、または夜間使用。

## チャクラとの関係
- **太陽神経叢チャクラ（Manipura / ソーラープレクサス）**: 自己肯定感・喜び・自分の力の座。
- 「内なる太陽を取り戻す香り」として使われる。
- 長期的な憂鬱・自己否定・不安の周波数を変えるとされる。

## 波動への繋がり
- 憂鬱は低い周波数（重さ・停滞）、ベルガモットのリモネン+リナロールは軽さと安定を同時にもたらす。
- 「光を食べて育つ柑橘が、光を奪われた心に光を返す」というアングル。
- 光感作性という特性が「光と一緒に使う精油」という詩的なメタファーになる。
- ナポレオンという孤独な皇帝が毎日必要とした香り → 偉大さの中の脆さを癒す香り。
