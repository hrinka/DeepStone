# POST-89 リサーチメモ — ローマンカモミール

## 基本情報
- 学名: Chamaemelum nobile（旧: Anthemis nobilis）
- 科: キク科（Asteraceae / Compositae）
- 原産: 西ヨーロッパ・北アフリカ
- 抽出部位: 花頭（flower heads）
- 抽出方法: 水蒸気蒸留
- 収量: 非常に低い（花100kgで約2〜3リットル）→ 高価な精油

## 名前の由来
- ギリシャ語 **khamaimelon**（地上のリンゴ）: khamai（地面に）+ melon（リンゴ）
- 踏みにじった時にリンゴのような甘い香りが上がることから命名
- ラテン語では「chamomilla」

## 歴史的背景
- **古代エジプト**: 太陽神ラーに捧げる聖なる植物。熱病の治療薬として記録。
- **1世紀ギリシャ**: ディオスコリデス「薬物誌（De Materia Medica）」に頭痛・解熱剤として記録
- **アングロサクソン（9〜10世紀）**: 写本「Lacnunga」に記された9つの聖なる薬草（Nine Sacred Herbs）のひとつ
- **シェイクスピア「ヘンリー四世」（1597年）**: "For though the camomile, the more it is trodden on the faster it grows..." → 「踏みにじられるほど速く育つ」という表現の典拠
- **中世イギリス**: カモミール・ローン（芝生の代わりに植える地面植え）/ バックファスト修道院など
- **ルネサンス期**: 「医師不要の植物」「家族のための薬草」として家庭菜園の定番

## 主要成分（ローマンカモミール精油）
- **イソブチルアンゲレート / 2-メチルブチルアンゲレート / イソアミルアンゲレート**: エステル類が全体の約75〜80%を占める（最も高いエステル比率を持つ精油のひとつ）
- エステルは鎮静・解痙・神経系を落ち着かせる作用の主な担い手
- カマズレン: ローマンカモミールには**ほぼ含まれない**（ドイツカモミールと区別する重要な点）

## ドイツカモミールとの違い

| | ローマンカモミール | ドイツカモミール |
|---|---|---|
| 学名 | Chamaemelum nobile | Matricaria chamomilla |
| 色 | 薄黄金色〜淡黄 | 深青〜インディゴ |
| カマズレン | ほぼなし | 15〜30%（主要成分） |
| 主成分 | エステル類（75〜80%） | カマズレン・α-ビサボロール |
| 主な作用 | 神経鎮静・感情面・解痙 | 抗炎症・皮膚ケア・抗アレルギー |
| 価格 | 高価 | 比較的安価 |
| 白魔女的角度 | 内なる子供・魂の作業 | 皮膚の炎症・物理的な修復 |

## 科学的根拠
- **2009年 J Clin Psychopharmacol（Mao JJ et al.）**: カモミール抽出物がGAD（全般性不安障害）の症状を有意に軽減（プラセボ比較）。カモミールのフラボノイドがGABA-A受容体に作用することが示唆されている。
- **抗炎症**: エステル類がCOX経路の一部を抑制
- **解痙（antispasmodic）**: 腸・子宮平滑筋の痙攣緩和——月経痛・IBS（過敏性腸症候群）への伝統的使用の科学的支持
- **鎮静**: 高濃度エステルが中枢神経系に直接作用→不安・緊張緩和

## 波動との繋がり（白魔女アングル）
- **内なる子供（Inner Child）**: アロマセラピストの間でローマンカモミールは「内なる子供の精油」として広く認識されている。幼少期に抑圧された感情（怒り・悲しみ・恐怖）を安全に感じる場を作る作用。
- **怒りの解放**: 感情的な停滞（波動低下の主要因）を解きほぐす
- **太陽のエレメント**: キク科の花として「太陽を象徴する植物」——太陽神ラーへの捧げ物という歴史が裏付ける
- **チャクラ**: 第3チャクラ（マニプーラ / 太陽神経叢）と関連が語られることが多い——自己肯定・意志・力の中枢
- **シェイクスピアの言葉**: 「踏まれるほど速く育つ」＝逆境から力を発揮する波動——ローマンカモミール自体の性質が象徴的なメッセージ

## 安全性
- 一般的に安全性が高い精油のひとつ
- 妊娠初期は使用を避けることが推奨される（子宮収縮誘発の可能性）
- キク科アレルギー（菊・アスター等）がある場合は注意
- 小児への使用: 薄めて使用すれば安全とされ、「子供のための精油」とも言われる
