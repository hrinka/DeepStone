# POST-46 リサーチメモ — マチュリティナンバー（成熟数）

## 基本情報
- 日付: 2026-06-04
- ピラー: 数秘（Numerology）
- 別名: 成熟数 / 晩年数 / Reality Number / Realisation Number

---

## 収集した情報

### 定義
マチュリティナンバーは、ライフパスナンバー（生年月日から計算）と表現数（ディスティニーナンバー、フルネームから計算）を足した数字。
人生後半——特に中年期以降に強く現れる、「その人が最終的になっていく姿」を示す。

### 計算方法
**ライフパスナンバー + 表現数（ディスティニーナンバー）= マチュリティナンバー**
- 2桁になった場合は一桁になるまで足し算を続ける
- 11・22・33はマスターナンバーとしてそのまま保持する

### 発現時期
- 30代後半から影響が出始める
- 40代で加速
- 50代以降で本格的に働く
- 早い人は30代で気づく場合も

### ライフパスとの違い
| | ライフパスナンバー | マチュリティナンバー |
|---|---|---|
| 示すもの | 生まれ持った性質・歩む道 | その道が向かう最終的な目的地 |
| いつ | 生涯通じて | 人生後半（35〜50歳以降） |
| 計算 | 生年月日 | ライフパス + 表現数 |

### 各マチュリティナンバーの傾向
- **1**: 真の自立とリーダーシップ。人生後半で「先頭に立つ」役割が明確になる
- **2**: 協調・深い絆・調和。他者との「繋がり」が使命になる
- **3**: 創造的表現・喜び・コミュニケーション。光で世界を照らす
- **4**: 安定・基盤構築・信頼。誰かの「安全地帯」になる
- **5**: 自由・変容・冒険。変化を体現し、教える存在になる
- **6**: 責任・愛・家族・調和の守護者。ケアが使命に
- **7**: 知的探求・自己認識・スピリチュアル開発。智慧の灯台
- **8**: 野心・権威・物質的成功と精神の統合。目標達成
- **9**: 理想主義・博愛・完成。社会全体への奉仕と貢献
- **11**: 高い波動・直観・人類への光
- **22**: マスタービルダー。大きな構造を現実に落とし込む

## 波動・スピリチュアルへの繋がり

- マチュリティナンバーは「最高の精神的・知的啓発を達成できる形」を示す（Stellar Fate）
