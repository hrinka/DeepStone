## コーナーストーンナンバーとは

### 定義
- 名前（ファーストネーム・名）をローマ字表記したときの**最初の文字**
- 数秘術における「名前の礎石」
- 英語では Cornerstone Number または Cornerstone Letter とも呼ばれる

### 語源・建築の比喩
建築におけるコーナーストーン（礎石）は、建物の角に最初に置かれる石。
この一石がすべての水平・垂直・角度の基準点になる。
数秘術でこの言葉を使うのは、名前の最初の文字が「あなたの行動様式のすべての基準点」に
なるという概念から来ている。

### ファーストヴォーウェルとの違い（POST-97との対比）
| | コーナーストーン | ファーストヴォーウェル |
|---|---|---|
| 対象 | 名前の最初の文字（子音・母音問わず） | 名前の最初の母音字 |
| 示すもの | 外への行動様式・始め方 | 内なる欲求・魂の渇き |
| 建築の比喩 | 礎石（外側の構造） | 内側に流れる水（隠れた動力） |

## 各数字のコーナーストーン特性

### 1（A / J / S）
- キーワード: 独立・先駆・意志・リーダーシップ
- 扉の開け方: 自分でドアを開ける。誰かが開けるのを待たない。
- 光と影: 行動力があるが、一人で突き進みすぎることも

### 2（B / K / T）
- キーワード: 感受性・共感・協調・直感
- 扉の開け方: ドアの向こうの気配を感じてから、そっと押す
- 光と影: 繊細でチームプレーが得意だが、優柔不断になりやすい

### 3（C / L / U）
- キーワード: 喜び・表現・創造・社交性
- 扉の開け方: ドアを開けながら、もう笑っている
- 光と影: 陽気で人を惹きつけるが、集中力が散漫になることも

### 4（D / M / V）
- キーワード: 堅実・構造・安定・実直
- 扉の開け方: 鍵が合うことを確かめてから、静かに開ける
- 光と影: 信頼できるが、変化に対して硬直しやすい

### 5（E / N / W）
- キーワード: 自由・冒険・変化・多様性
- 扉の開け方: ドアが見えた瞬間、もう走り出している
- 光と影: エネルギッシュで好奇心旺盛だが、一つに留まれないことも

### 6（F / O / X）
- キーワード: 愛・責任・調和・家族
- 扉の開け方: 開けたドアを押さえて、後ろを振り返る。みんなを先に通す
- 光と影: 愛情深いが、自分を後回しにしすぎることも

### 7（G / P / Y）
- キーワード: 探求・内省・神秘・スピリチュアリティ
- 扉の開け方: ドアの前で立ち止まる。見えないものを感じるまで、急がない
- 光と影: 深みがあるが、孤独になりやすく踏み出しが遅れることも

### 8（H / Q / Z）
- キーワード: 野心・力・豊かさ・権威
- 扉の開け方: そのドアのオーナーになることを考えながら、開ける
- 光と影: 実力があるが、コントロール欲が強くなることも

### 9（I / R）
- キーワード: 慈愛・知恵・解放・人道主義
- 扉の開け方: 通り抜けた後、次に来る人のために、開けたままにしておく
- 光と影: 思いやりが深いが、自己犠牲になりすぎることも

## 波動との繋がり

名前の最初の文字は「始まりの周波数」。人が新しいことを始めるとき（新しい仕事、新しい関係、新しい朝）に、自動的にこの周波数が立ち上がる。意識することで、その周波数を意図的に使えるようになる。「今日、私は何番の扉を開けようとしているか」という問いが、波動の引き上げ装置になる。
