# POST-77 — リサーチメモ: クラリセージ（Salvia sclarea）

## 基本情報
- 学名: Salvia sclarea
- 科: シソ科（Lamiaceae）
- 産地: 地中海沿岸（フランス・ロシア・モロッコ・ブルガリア・イタリア）
- 抽出部位: 花穂と葉（水蒸気蒸留法）
- 精油の色・香り: 透明〜薄黄緑、スウィートで少しマスカットのようなムスキーな香り

## 語源・歴史
- "Clary" = ラテン語 **clarus**（明るい・澄んだ）← 目の薬草として使用されたことが語源
- 中世名: **Oculus Christi**（キリストの目）— 眼の疾患に外用
- 古代名: 1世紀 ペダニオス・ディオスコリデス『De Materia Medica』に**"Clear Eye"**として記録
- 中世ヨーロッパ: 修道院薬草園で栽培。種子の粘液で異物除去に使用（Nicholas Culpeper記録）
- 別名「**Muscatel Sage（マスカテルセージ）**」: 中世ドイツでライン川沿岸のワインにこの草を加え、高価なマスカット風ワインに似せて醸造された
- ビール醸造にも使用（ホップ普及以前）——ただし過剰摂取で幻覚・強い酩酊効果があるとされる

## 主要成分
| 成分 | 含有率 | 主な作用 |
|------|--------|---------|
| 酢酸リナリル（Linalyl acetate） | 51〜75% | 鎮静・鎮痛・緊張緩和・GABA-A受容体活性化 |
| リナロール（Linalool） | 10〜17% | 抗不安・鎮静・血圧降下 |
| スクラレオール（Sclareol） | 1〜5% | エストロゲン様作用・ホルモン調整 |
| ゲルマクレンD（Germacrene-D） | 〜6% | 抗炎症 |

- 酢酸リナリルとリナロールはラベンダーと共通成分（クラリセージのほうが含有量が多い場合も）

## 科学的根拠
1. **コルチゾール・セロトニン研究（2014年、韓国）**
   - 更年期女性22名にクラリセージ精油を5分間吸入させる実験
   - 結果: コルチゾール（ストレスホルモン）**31〜36% 低下**
   - 血中セロトニン（5-HT）**有意に上昇**
   - 抗うつ様・抗不安様の神経内分泌効果を確認
   - 出典: Phytotherapy Research 2014 / DOI: 10.1002/ptr.5163

2. **オキシトシン研究（2017年、PubMed 29216912）**
   - 出産期の女性への吸入 → オキシトシン（愛情・つながりのホルモン）上昇
   - フィジビリティパイロット研究

3. **GABA-A経路**
   - 酢酸リナリルがGABA-A受容体を活性化 → 中枢神経抑制 → 抗不安効果
   - ラベンダーでも同様のメカニズムが確認されている

## 女性ホルモンとの関係
- スクラレオールの分子構造がエストロゲンに類似（フィトエストロゲン様）
- PMS・月経不順・更年期の諸症状（ほてり・イライラ・睡眠障害）の緩和に活用
- ⚠️ **子宮収縮作用があるため妊娠中は使用禁止**

## 波動との繋がり
- 「澄んだ視界・ビジョン」が名前そのものに刻まれている
- コルチゾールが高い状態 → 判断力低下・視野狭窄・不安増大
- クラリセージでコルチゾールを静める → 心が澄んで本質が見えてくる
- 第6チャクラ（サードアイ・インディゴ）と対応するとされる（伝承）
- 「心が騒いでいるとき、答えは見えない。クラリセージは静かに騒音を止める」
