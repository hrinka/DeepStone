# POST-42 リサーチメモ — パセリと死の庭

パセリ（Petroselinum crispum）— ハーブ菜園ピラー

## 収集した主要情報

### 神話・歴史
- **アルケモラス神話**: ネメア王リュクルゴスの息子の死の血から最初のパセリが生えたとされる。英雄の死のシンボル。
- **葬儀の植物**: 古代ギリシャで墓に撒かれ、葬礼の花冠に用いられた
- **「パセリしか要らない」**: 「もう片足があの世にある」を意味したギリシャ語の慣用句
- **競技勝者の冠**: イストミア競技会でパセリの冠が優勝者に授けられた → 死と勝利の両象徴
- **ローマ**: ペルセポネ（冥界の女王）に捧げられた神聖なハーブ

### 中世ヨーロッパの伝承
- 「種は悪魔のところへ9回行って戻ってくる」 → 発芽が非常に遅いことの民間説明
- 玄関にパセリを置く → 悪霊・邪悪なエネルギーを防ぐお守り
- 魔女の薬草リストに登場（保護・浄化・死者との通信）

### 科学的成分・効能
- **アピゲニン**: 215mg/100g（最も豊富な食品の一つ）
  - 脳の神経炎症を鎮静
  - Nrf2経路活性化 → 抗酸化酵素（GSH合成酵素、カタラーゼ、SOD）産生
  - 神経保護 → 神経変性疾患予防研究が進行中
- **ルテオリン**: 神経炎症抑制・認知機能保護・NF-κBシグナル抑制
- **ビタミンK**: 骨形成・血液凝固
- **ビタミンC**: 免疫・コラーゲン合成
- **クロロフィル**: 血液浄化・解毒
- **鉄分・葉酸・カルシウム**: 造血・神経系サポート

### 波動との繋がり（コンテンツ視点）
- 死と再生の両面 → 変容・浄化のエネルギー
- 脳神経保護 = 意識の明晰化 = 周波数の安定・向上
- 古代人の直感（「冥界を往復してきた」）が科学的に「脳の深部を守る」として現れた
- 「最も地味な存在が最も深い守護」という逆説 → 白魔女的世界観と一致
