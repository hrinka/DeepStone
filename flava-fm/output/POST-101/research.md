# POST-101 リサーチメモ — ゼラニウム精油

## 基本情報

| 項目 | 内容 |
|------|------|
| 学名 | Pelargonium graveolens / Pelargonium roseum |
| 科名 | フウロソウ科（Geraniaceae） |
| 原産地 | 南アフリカ（喜望峰周辺） |
| 主要産地 | エジプト・レユニオン島・インド・モロッコ |
| 抽出部位 | 葉と茎 |
| 抽出方法 | 水蒸気蒸留法 |
| 香りのノート | ミドルノート |

## 主要成分と作用

| 成分名 | 割合（目安） | 主な作用 |
|--------|------------|---------|
| シトロネロール | 20〜40% | 自律神経調整・鎮静・防虫 |
| ゲラニオール | 10〜30% | 抗菌・皮膚修復・ローズ様の香り |
| リナロール | 5〜15% | 鎮静・抗不安・神経系サポート |
| フォルメートエステル類 | 〜15% | 香りの構成・甘さと深み |

## 歴史的背景

- **南アフリカ原産**: ペラルゴニウム属は喜望峰周辺が原産。先住民が傷の治療・消化器系疾患に使用
- **17世紀 → ヨーロッパへ**: オランダの探検家が持ち帰り、フランスで栽培が始まる
- **19世紀 → レユニオン島へ**: 香水産業の需要でインド洋のレユニオン島・コモロ諸島へ
- **古代エジプト**: クレオパトラがスキンケア儀式に使用したと語り継がれる（歴史的確証は文化伝承レベル）
- **アーユルヴェーダ**: 南アジアでも古くから薬用・儀式用に使用

## 科学的・生理学的根拠

- **副腎への作用**: ゼラニウムの芳香成分が嗅覚を通じて視床下部・副腎に作用し、コルチゾール（ストレスホルモン）の分泌調整に関与するとされる
- **PMS・更年期**: ホルモン様作用（phytoestrogen類似）により、月経前症候群・更年期のホットフラッシュ・イライラを緩和する効果が複数の臨床報告で示唆
- **抗炎症**: ゲラニオールは COX-2 阻害による抗炎症作用（NCBIの研究: PMC3793238）
- **抗菌**: 皮膚感染・口腔内の抗菌作用（Staphylococcus aureus等に有効）
- **神経系**: リナロールがGABA受容体に作用し、鎮静・抗不安効果
