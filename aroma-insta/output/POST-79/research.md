## 計算方法
2 + 0 + 2 + 6 = 10 → 1 + 0 = **1**
2025年は9（2+0+2+5=9）、2026年でサイクルが完全にリセット。

## ユニバーサルイヤーとは
- 西暦の数字を足して1桁にした数字
- 個人ではなく「世界・地球全体が共有するサイクルのエネルギー」
- ピタゴラス数秘術の体系に基づく（パーソナルイヤーと同じ計算構造だが個人の誕生日は入らない）

## パーソナルイヤーとの違い
| 概念 | 計算方法 | 対象 |
|------|----------|------|
| ユニバーサルイヤー | 西暦の数字合計 | 地球全体・全人類 |
| パーソナルイヤー | 誕生月+誕生日+ユニバーサルイヤー | 個人のみ |

→ パーソナルイヤーがユニバーサルイヤーと同じ数字の年は、エネルギーが特に強く現れる。Rinkaは2026年のパーソナルイヤー = 3+10+1 = 14 → 5（POST-31参照）。

## 9年サイクルの構造
1年 → 2年 → 3年 → 4年 → 5年 → 6年 → 7年 → 8年 → 9年 → 1年（リセット）

各年の意味（ユニバーサル・個人どちらにも共通）：
- **1**: 始まり・種まき・自立・新しいアイデンティティ
- **2**: 待機・協力・感受性・関係性
- **3**: 創造・表現・社交性・芽吹き
- **4**: 基盤・構築・忍耐・実務
- **5**: 変化・自由・旅・拡張
- **6**: 責任・愛・家庭・癒し
- **7**: 内省・霊性・学び・静寂
- **8**: 達成・物質・権威・収穫
- **9**: 手放し・完了・循環・総決算

- **2008年**: 世界金融危機でグローバル経済の秩序リセット / ビットコン白書の発表（サトシ・ナカモト） / オバマ大統領選出（世代交代のシグナル）
- **2017年**: #MeToo運動の爆発的拡散 / ブロックチェーン・暗号資産が主流化 / 各国で政治の「新時代」が始まった

→ 1の年はいつも「古い秩序の終わりと、新しい種の始まり」が同時に起きる。

## 「1」の数字の象徴
- 始まり・創造の一歩目

- タロットでは「魔術師（Magician）」= 意志と行動の象徴
- 占星術では牡羊座のエネルギーと共鳴（火・始まり・衝動）
