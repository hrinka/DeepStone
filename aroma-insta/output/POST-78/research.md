# POST-78 リサーチメモ — 精油は植物の防衛物質

## トピック
精油（テルペン）が植物の自己防衛システムであること。特に真夏の熱・紫外線ストレスに対する地中海ハーブの戦略。

---

## 核心的科学事実

### 1. テルペンとは
- 精油の主成分（精油の20〜60種の成分のほとんどがテルペン類）
- 揮発性有機化合物（VOC）の一種
- Lamiaceae科（シソ科）= ラベンダー・ローズマリー・セージ・タイム・バジル等、最も重要な精油産生植物群

### 2. 植物がテルペンを作る理由（防衛機能）
科学的に確認されている機能:
- 草食動物・昆虫への忌避（香りで攻撃を防ぐ）
- 病原菌・カビへの抵抗
- **活性酸素（ROS）のスカベンジャー = 植物の抗酸化物質**
- **光酸化ストレス（紫外線）からの保護**
- **熱ストレスからの保護（thermo-protection）**
- 受粉者（ハチ・蝶）の誘引
- 隣接植物との化学コミュニケーション

### 3. 熱ストレスとテルペン放出量の関係 ← 核心
- **気温が上がるほど、モノテルペンの放出量は増加する（指数関数的に）**
- 揮発性イソプレノイド（イソプレン・モノテルペン）が:
  - クロロプラスト膜（チラコイドグラナ）の構造を高温から守る
  - ROS（活性酸素）を除去して細胞を守る
  - 熱ショックタンパク質（HSP）の誘導を助ける
  - 光合成の継続を維持する
- 出典: Cell / Trends in Plant Science（2025）、ScienceDirect

### 4. グランデュラー・トリコーム（毛状腺体）
- 葉の表面にある微小な分泌器官
- ラベンダー・セージ・ローズマリー・タイムの葉の「銀色の毛」の正体
- 精油（テルペン類）を合成・貯蔵する器官
- 2種類: 腺性トリコーム（精油分泌）と非腺性トリコーム（物理的保護）
- 葉の銀白色の外観 = 密なトリコームによるUV反射

### 5. 地中海ハーブの夏適応戦略
- 原産地（地中海沿岸）の夏: 高温・乾燥・強い日差し
- 適応戦略:
  a. 細かく小さい葉 → 表面積減少で蒸散を抑える（タイム）
  b. 銀灰色の葉・密なトリコーム → 日光反射（ラベンダー・セージ）
  c. 精油の大量産生 → ROS除去・熱保護（全種共通）
  d. 深い根系 → 乾燥時に深部の水分へアクセス

「植物は戦っている。静かに、毎日。」
→ 精油の香りを嗅ぐとき、その植物が生き延びるために作った知恵を直接受け取っている

- テルペンは「植物が最も高い周波数で機能しているとき」に最も多く放出される
