# POST-56 リサーチメモ — ローズオットー（ダマスクローズ）

## 基本情報
- 植物名: Rosa damascena（ダマスクローズ）
- 精油名: ローズオットー（Rose Otto）/ ローズアブソリュートとは別物（蒸留 vs 溶剤抽出）
- 主産地: ブルガリア「バラの谷」（Kazanlak周辺）、トルコ → 両国で世界生産の約80%
- 採取部位: 花（花びら）
- 抽出方法: 水蒸気蒸留

## 生産に関する数字
- 1kgの精油に必要な花: 3.5〜5トン（約350〜500万輪）
- 収穫期間: 毎年5月〜6月上旬のわずか20日間
- 収穫方法: 夜明け前（3〜6時）に手作業で摘む（日が昇ると香り成分が揮発する）
- 価格: 10mLで数千〜1万円以上。純粋なローズオットーは精油最高価格クラス

## 歴史
- 5000年以上前からペルシャ（現イラン）・インドで使用
- 13世紀: 十字軍がダマスカスから欧州に持ち帰る → 「ダマスクローズ」の名の由来
- 中世イスラム医学: アヴィセンナ（イブン・スィーナ）が蒸留法を確立し薔薇水を作った
- ルネサンス期: ヨーロッパ上流階級の薬・香水の主役
- 現代: 高級香水（Chanel, Dior等）のベース素材

## 主要芳香成分
- シトロネロール（Citronellol）: 30〜40%
- ゲラニオール（Geraniol）: 10〜25%
- ネロール（Nerol）: 5〜10%
- リナロール（Linalool）: 1〜3%
- その他600種以上の芳香成分が微量で存在
→ 単一成分で「薔薇の香り」を再現できない理由

## 科学的研究
1. **臨床試験（血液透析患者）**: ダマスクローズ精油の芳香吸入 → 不安・うつ・ストレス指数が有意に低下
   - 出典: researchgate.net/publication/319923477
2. **術前不安軽減研究（ScienceDirect）**: 手術前患者へのローズオイル芳香吸入 → 不安スコア低下
   - 出典: sciencedirect.com/science/article/abs/pii/S1876382018309314
3. **ドーパミン放出**: ローズオイルがドーパミン分泌を促進 → 抑うつ症状の改善
4. **生理的効果**: 血圧・心拍数・コルチゾール（ストレスホルモン）低下
5. **逆説**: 「落ち着くのに気分が上がる」— メリッサ（POST-53）やベルガモット（POST-50）と共通する「沈静×高揚の逆説」

## 波動との繋がり
- **ハートチャクラ（第4チャクラ）対応**: 愛・感受性・繋がりをつかさどるチャクラ
- **アフロディーテの花**: ギリシャ神話で愛の女神がローズを自らのシンボルに選んだ
- **「摘まれた瞬間に開く」**: つぼみが閉じているのは守っているから。触れることで香りが解放される → 愛の比喩
- **600の声の統合**: 複雑で多面的な成分が共鳴して「薔薇」になる → 複雑な感情も全部で「あなた」である
- **密度のメタファー**: 350万輪が1kgに凝縮される = 感情・経験・痛みが愛に変わるプロセス
