# POST-02 リサーチメモ

## トピック
フランキンセンス（乳香）精油 — 歴史・瞑想・スキンケア活用

## 収集した情報

### 基本情報
- 学名: Boswellia sacra（主要種）/ Boswellia carterii など複数種
- 原料: ボスウェリアの木の幹に傷をつけて採取した樹脂（白色〜琥珀色）を水蒸気蒸留
- 主産地: オマーン、ソマリア、エチオピア、インド
- 香りの特徴: スパイシーでウッディ、バルサム調の深みのある香り。煙のような渋さがある
- 別名: 乳香（にゅうこう）/ Olibanum（オリバナム）

### 歴史
- 5000年以上使われてきた。古代エジプトでは神殿での儀式・ミイラの防腐処理に使用
- 古代ローマ・ギリシャ・ペルシャ・中国で宗教的儀式の「聖なる煙」として用いられた
- アーユルヴェーダ（インドの伝統医学）でも古来より使われる薬草
- キリスト教の聖書でも「三賢者が贈った黄金・乳香・没薬」のひとつとして登場
- かつては金と同じ重さで取引された時代もある

### 主な効果・効能
- **鎮静作用**: 不安・イライラを静める。呼吸を深く、ゆっくりにする
- **抗炎症作用**: ボスウェリン酸という成分が炎症を抑える可能性（研究あり）
- **スキンケア**: 「若返りのオイル」と呼ばれる。皮膚再生作用。乾燥・肌荒れ・エイジングケアに
- **呼吸器サポート**: 気道を広げて深い呼吸を促す
- **精神的効果**: 瞑想・集中力向上。心を「今ここ」に戻す作用

### 使い方
| 用途 | 方法 |
|------|------|
| 瞑想・リラックス | ディフューザーに1〜2滴 |
| スキンケア | キャリアオイル（ホホバなど）10mlに対して1滴（1%以下に希釈） |
| 呼吸サポート | マグカップの湯気にフランキンセンス1滴、顔を近づけてゆっくり吸入 |
| バスタイム | 入浴剤（ミルクや塩）に希釈してから1〜2滴 |

### ブレンド相性
- **ラベンダー**: 鎮静効果が高まる。睡眠前のリラックスに
- **サンダルウッド**: 深みとグラウンディング感が増す。瞑想に最適
- **ベルガモット**: フレッシュさが加わって昼間も使いやすくなる
- **シダーウッド**: アーシーさが増す。安定感のある香りに
- **ローズ / イランイラン**: 高貴で甘い香りに。スキンケアブレンドに向く

### 注意事項
- 妊娠中は使用を避けるか医師に相談
- 原液は肌に直接つけない（必ずキャリアオイルで希釈）
- 品質差が大きい精油のひとつ。Boswellia carterii か Boswellia sacra の表記があるものを選ぶ
