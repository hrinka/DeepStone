## 語源・名前
- "lavender" ← ラテン語 **lavare**（洗う）
- 中世ヨーロッパで洗い女（laundress = "lavenders"）が洗濯物をラベンダーの茂みに干す習慣から
- POST-84のラベンダー歴史メモ（語源: ラテン語 lavare → 中世洗濯女はlavenders）と直接接続

## 歴史の線
| 時代 | 用途 |
|------|------|
| 古代エジプト | ミイラ作り・副葬品・香水 |
| 古代ローマ | 公衆浴場の湯・衣類の香り付け・防虫 |
| 中世 | ペスト対策・窓辺に束ねて香りで病を払う・修道院薬草園 |
| 17世紀イギリス | チャールズ一世の宮廷でラベンダー水（lavender water）が流行 |
| 1910年フランス | ガットフォセの火傷事故→近代アロマテラピーの起点 |
| 1937年 | Gattefossé 著書 "Aromathérapie" 出版（"aromatherapy"という単語の初出） |
| 2025年 | 628名参加・11RCTの系統的レビューで睡眠改善効果確認 |

## René-Maurice Gattefossé（1881–1950）
- フランス・リヨン生まれの化学者・調香師
- 家業はアルベール・ヴィオレ社（香料会社）
- 1910年: 研究室の爆発事故 → 重度熱傷 → 近くにあったラベンダー精油に手を浸す → 予想外の早さで治癒
- 「ガスの壊疽になりかけた手がラベンダー油で48時間以内に回復した」（本人の記述より）
- Robert Tisserand（アロマテラピー研究者）が2011年に「ガットフォセの火傷」の詳細を検証・修正: 実際は「gaseous gangrene」ではなく「tissue gangrene」に近い状態だった可能性
- 1937年に "Aromathérapie" 出版 → 1993年英訳 "Aromatherapy" として出版されて初めてこの単語が英語圏で定着
- "aromatherapy" という言葉はGattefossé 自身が造語

## 主要成分（真正ラベンダー / Lavandula angustifolia）
| 成分 | 含有量 | 主な作用 |
|------|---------|---------|
| 酢酸リナリル（Linalyl acetate） | 30〜50% | GABA-A受容体活性化・鎮静・睡眠導入 |
| リナロール（Linalool） | 20〜40% | セロトニントランスポーター作用・抗不安 |
| β-オシメン | 数% | 抗菌 |
| テルピネン-4-オール | 少量 | 抗炎症 |
| カンファー | 微量 | 刺激（真ラベンダーは低含量が品質基準） |

※ ラバンジン（Lavandula × intermedia、Grosso等）は交雑種でカンファー高め → 真ラベンダーと効果が異なる

## 科学的根拠
- **睡眠**: 2026年 Holistic Nursing Practice: 系統的レビュー・628名・11RCT → 睡眠の質向上確認
- **不安**: 2025年 Food Science & Nutrition (Wiley): Lavandula angustifolia の抗不安効果に関する包括的レビュー
- **神経系**: 2026年 ScienceDirect: 抗不安・抗うつ・催眠機能の生物学的機序レビュー
- **術後睡眠**: 2025年 Frontiers in Pharmacology: 脳腫瘍術後患者へのラベンダー吸入 → 睡眠の質改善（RCT）
- 酢酸リナリル濃縮フラクション → 睡眠導入に優位
- リナロール濃縮フラクション → 睡眠維持に優位

## チャクラ対応
- **第7チャクラ（サハスラーラ / クラウン）**: 宇宙との接続・霊性・一体感の開放
- **第6チャクラ（アジナー / サードアイ）**: 直感・洞察・内なる視力の研ぎ澄まし
- 「すべてのチャクラに作用する唯一の精油」= アロマテラピーの"母"と呼ばれる所以

## 波動との繋がり（白魔女アングル）
- 数千年間「洗い女」たちが無意識に実践していた浄化の儀式が、2025年の科学で証明された
- GABA受容体と副交感神経の活性化 = 体が「戦い」モードから「修復」モードへ移行する周波数の変化
- 「眠れないのは波動が下がっているのではなく、上がりすぎているから」——ラベンダーは興奮した周波数を地面に戻す
- 手放しのアロマ: 委ねること自体が波動を整える行為
