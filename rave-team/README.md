# Dive into Rave Culture — Team Setup

## How to use

### Start a new episode
Claude Codeでこのディレクトリを開いて言うだけ：

```
新しいエピソード: UK Rave Scene origins
```

or

```
new episode: Dubstep vs Brostep
```

Producerが自動でチーム全員に仕事を振り、以下を生成する：
- `output/EP-{N}/research.md` — リサーチ
- `output/EP-{N}/script.md` — 台本（60秒）
- `output/EP-{N}/production_brief.md` — 映像・音の指示書
- `output/EP-{N}/social.md` — 各SNS投稿文 + ハッシュタグ

### Revision
```
スクリプトをもっとエネルギッシュにして
ディレクターブリーフのBGM提案を変えて
```

### Check status
```
エピソード一覧を見せて
```

## Team
| Agent | Role |
|-------|------|
| Producer | 全体統括・パイプライン管理 |
| Researcher | ジャンル・歴史・文化リサーチ |
| Scriptwriter | 60秒台本制作 |
| Director | 映像・音・テキスト構成指示 |
| Social Manager | SNS投稿文・ハッシュタグ・投稿スケジュール |

## Goal
収益化まで続ける。
