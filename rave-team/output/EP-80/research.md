# EP-80 リサーチメモ — Shy FX & UK Apache / "Original Nuttah" (1994)

## トピック選定理由
- EP-11（Jungle誕生）・EP-12（DnB進化）・EP-76〜79（DnBアーティスト群）でジャングルの誕生と展開を複数回描いてきたが、**ラガ・ジャングル**（ragga jungle）というサブジャンル、およびその定義曲「Original Nuttah」は未出
- Count Shelley（Shy FXの祖父）→ Shy FX というサウンドシステム直系の血統はEP-54（King Tubby）・EP-64（Jah Shaka）・EP-02（Sound System）との接続として重要
- UK Apacheの「成功の絶頂で消えた」物語はCarousel的なフックが強い

## UK Apache（Abdul Wahab）プロフィール

| 項目 | 内容 |
|---|---|
| 本名 | Abdul Wahab |
| 出身 | ロンドン生まれ育ち |
| 家族背景 | イラク人の父 × インド南アフリカ人の母のムスリム家庭 |
| 音楽との出会い | ロンドンの黒人コミュニティ（主にジャマイカ系近隣者）からDub・サウンドシステム・ルーツレゲエを習得 |
| 歌詞の起源 | "Original Nuttah"の歌詞は1980年代後半に書かれたもの |
| ジャンル後の行動 | 成功のピーク直後に音楽業界から距離を置く。理由：「周囲に裏切られた感覚、信頼できる人がいなかった」 |
| 引用 | "I felt people were trying to cheat me — I was confused and angry and I had no one to trust. It was too much pressure, so I stepped away." |
| その後 | イスラームへの傾倒を深め、ムスリムとしての発信活動（講演など）へ移行。後に音楽活動にも部分的に復帰 |

## ラガ・ジャングル（Ragga Jungle）とは

- ジャングル（Hardcore / Jungle）にダンスホール・レゲエのMCスタイルを融合させたサブジャンル
- BPM: 160〜180（Amen Breakを軸にした高速ブレイクビート）
- 低音: サウンドシステム由来の重いサブベース
- ヴォーカル: ラガスタイル（ダンスホール的なシャウト、スキャット、MC tracing）
- 代表的プロデューサー: Shy FX、Congo Natty（Rebel MC）、Gunsmoke、Nookie
- Shy FXはこのサブジャンルの最も重要な定義者のひとり
