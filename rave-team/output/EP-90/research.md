## Key Facts Confirmed

| Fact | Detail |
|---|---|
| Original track | "Amen, Brother" — B-side of "Color Him Father" (The Winstons, 1969) |
| Label | Metromedic Records |
| Drummer | Gregory "G.C." Coleman |
| Bandleader | Richard Lewis Spencer (sax/vocal) |
| Grammy | "Color Him Father" — Best R&B Song, 1970 (12th Grammy Awards) |
| Break position | ~1 min 26 sec into "Amen, Brother" |
| Break duration | 6〜7 seconds (4 bars) |
| First major hip-hop uses | N.W.A "Straight Outta Compton" (1988), Rob Base & DJ E-Z Rock (1988) |
| UK Jungle breakthrough | 4hero, Shy FX, Reinforced Records crew — early 1990s |
| BPM transformation | 100 BPM (original) → 160〜170 BPM (UK jungle) |
| Total samples | 4,500〜5,000+ tracks (WhoSampled) |
| Coleman's death | Atlanta, 2006. Homeless. Zero royalties. |
| Spencer's awareness | Discovered sampling in 1996 — statute of limitations already passed |
| Spencer's death | December 26, 2020. Age 78. |
| Crowdfunding | 2015 — DJ Martyn Webster raised ~£24,000 for Spencer |

## Creative Angle (Charlotte R1nR1n Perspective)

フックは「無名のB面に宿った、知られざる6秒」。

- Tragedy: 最もサンプリングされたドラマーが、そのことを知らないまま死んだ
- Paradox: 誰も聴かなかったB面が、1000万人を踊らせた
- Connection: このブレイクなしに、Jungle・DnB・Breakcore・多くのUKレイブ音楽は存在しない
- Cultural weight: 「Color Him Father」（継父への感謝の歌）がグラミーを取り、「Amen, Brother」（無名のB面）が世界を変えた——A面とB面の逆転劇
