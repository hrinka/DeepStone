# POST-07: 黄色いスマイルは、失敗から生まれた

## メタ
- テーマ: Acid House — Roland TB-303 の廃番とスマイリーフェイスの起源
- 長さ: 50〜60秒
- BGM: Phuture "Acid Tracks" (1987) / S-Express "Theme From S-Express" (1988) / 808 State "Pacific State"

## スクリプト

### フック（冒頭3秒）
「ローランドが捨てた機械が、世界を動かした。」

### 本編（30〜40秒）
1981年。
ローランドが出したシンセがある。
TB-303。

ベースギターの代わりになるはずだった。
売れなかった。
1984年、製造中止。
50ドルで処分された。

シカゴの若者が買った。
使い方がわからなかった。

ダイヤルをいじった。
音がうねった。ひずんだ。叫んだ。

DJ Pierreは後に語る。
「事故だった。303の使い方を知らなかっただけ。」

そのトラックを、Ron Hardyがかけた。
フロアは戸惑った。
同じ曲を4回。
やっと踊り始めた。

1987年。「Acid Tracks」。
翌年ロンドンへ。Shoomへ。

黄色いスマイルのバッジ。
Danny Ramplingが言った。
「これが、この動きのすべてだ。」

The Sunが書いた。「クールでイカしてる。」
7日後。同じ紙面。「エクスタシーの悪。」

### 締め
「失敗作が、文化になる夜がある。」 🖤

## キャプション
1981年、売れなかった機械があった。
廃番。50ドルで処分。
シカゴの若者が使い方も知らずに買った。
その「事故」が、アシッドハウスになった。
黄色いスマイルが生まれた。
世界が踊り始めた。 🖤
