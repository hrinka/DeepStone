# EP-47: Metalheadz — 日曜の地下室が、世界で一番暗い部屋だった

## メタ
- テーマ: Metalheadz レーベルと Blue Note Sunday Sessions（1994〜1999）
- 長さ: 50〜60秒
- BGM: Goldie「Inner City Life」(1994) または Photek「Ni-Ten-Ichi-Ryu」(1996)

## スクリプト

### フック（冪頭3秒）
「日曜の夜だけ、ロンドンに世界で一番暗い部屋が開いた。」

### 本編（35〜40秒）

ゴールディーは3歳で施設に預けられた。

グラフィティを描いた。金歯を売って生きた。

ある夜、Rage というクラブでドラムンベースを聴いた。
「これを作りたい」と思った。

1994年——Metalheadz が生まれた。

翌年、Hoxton の荒廃した路地、Blue Note というクラブで、
日曜日の夜だけ扉が開いた。

天井は低かった。
ベースは逃げなかった。
照明は暗かった。

Photek、Dillinja、Grooverider。
まだ誰も知らない名前たちが、毎週日曜に歴史を作っていた。

1995年、ゴールディーのアルバム「Timeless」がリリースされた。
22分のブレイクビート・シンフォニー。
UKチャート7位。
ドラムンベースが「音楽」と呼ばれた、最初の瞬間。

### 締め
「1999年、Kemistry が事故で逝った。Blue Note の夜も終わった。
でも、あの部屋のベースはまだ、どこかに残っている。🌑」

## キャプション
1994年、世界で一番有名なドラムンベースレーベルが生まれた。
創設者は施設育ちのグラフィティアーティストだった。
毎週日曜、ロンドンの廃れた一角で、歴史が作られていた。
Metalheadz — 知っておいてほしいレーベルがある。🖤
