# Production Brief: EP-01 — Raveとは何か

## Shot-by-Shot Breakdown

| Time | Visual | Text On Screen | Audio |
|------|--------|----------------|-------|
| 0–1s | 漆黒の画面。何もない。 | （なし） | 低周波のサブベース、息をのむような静寂 |
| 1–3s | フラッシュ：野原の群衆シルエット、逆光。顔は見えない。 | **「コンサートには行ったことがある。」** (白・極細) | ベースがゆっくり入り始める |
| 3–5s | 瞬間カット：暗い倉庫の中、レーザー光線が走る。 | **「でもこれは違う。」** (大・白・センター) | ドラムキックが一発。止まる。 |
| 5–8s | アーカイブ映像風：夜の幹線道路。車のテールライト。向かう人々。 | 「場所を知らないまま向かう。」 | 環境音（タイヤ音・風） + 遠くから聞こえるベース |

| 12–14s | タイトルカット：暗黒に白文字 | **「それがレイブだった。」** | 一瞬の無音 → キックが始まる |

| 18–22s | 封筒・電話・暗号のようなイメージ（コラージュ）| 「住所は当日の夜に明かされる。」 | BPM 130前後のループ、低く |

| 26–30s | デジタル時計 → 03:00 → 05:00 → 07:00と時間が飛ぶ | **「終わりの時間も、ない。」** | ループが続く。止まらない。 |
| 30–36s | クロースアップ：床で踊る足。知らない人の肩。汗。暗闇とライト。 | 「暗闇の中でベースが身体を叩く。隣に誰がいるかわからない。」 | ベースが体に直接届くような低音 |
| 36–40s | 群衆の俯瞰 → 全員が同じ方向を向いていない。それぞれが動いている。 | **「それでも、全員が同じ音の中にいる。」** | 音楽がピークに向かう |
| 40–44s | 静止した一枚：野原の地平線、夜明け前の空 | 「知らないまま向かって、着いて、初めてわかる。」 | 音楽が引く。静かになる。 |
| 44–48s | 白いテキストのみ、ゆっくりフェードイン | **「それがレイブという体験の正体だ。」** | サブベースのみ、低く |
| 48–54s | レコードが回る。手が盤面に触れる。 | 「Larry Heard — Can You Feel It (1986)」/ 小テキスト「4分間、何も変わらない。でも変わるのは自分の方だ。」 | "Can You Feel It" の冒頭フレーズ（3〜4秒） |
| 54–59s | シリーズロゴ + 次回予告テキスト | **「次回：PLUR」**「Dive into Rave Culture」 | ベースが静かに消えていく |

## Typography Spec

**Font style:** Grotesk系 sans-serif（推奨：Space Grotesk / Monument Extended / Helvetica Neue Bold）
**Background:** #080808（ほぼ黒）
**Accent color:** Cyan #00FFFF または Magenta #FF00FF（このエピソードはCyan推奨）

**Key words to EMPHASIZE in big text:**
- 「これは違う。」— 画面幅90%、センター配置
- 「電話番号しかない。」— モノスペースフォント、タイプライター効果
- 「終わりの時間も、ない。」— ゆっくりフェードイン、1文字ずつ
- 「それがレイブだった。」— 最大サイズ、1秒間静止してからフェードアウト

**Transition style:** ハードカット主体。感情の山でのみ0.2秒フラッシュカット。スライドは使わない。

## Director's Note

このエピソードの視聴者はレイブを「知識」としては知っていても、体感したことがない。だからこの映像の仕事は「説明」ではなく「感覚の移植」だ。

画面に映るのは顔ではなく、動き・光・テキスト・音。視聴者が「そこにいる」感覚を60秒で作る。

ペースの鍵：前半（0–14s）はゆっくりと、でも引く力がある。後半（30–44s）は身体的。最後（44–59s）は静かな確信。大声を上げない——本当のことは静かに言える。

視聴者がこの動画を見終えて「次を見たい」ではなく「もっとこの感覚を知りたい」と思えれば成功。シリーズ全体のトーンを決める最初の60秒。丁寧に作れ。
