# EP-41: 服が抵抗になった夜 — Instagram カルーセル

## カラーパレット
- メインカラー: `#0D0D0D`（ほぼ黒）
- アクセント1: `#F5C518`（スマイリーの黄色）
- アクセント2: `#FF6B00`（フルオロオレンジ）
- テキスト: `#F0EFE9`（オフホワイト）
- ムード: 時代ごとにトーンが変わる — 黄色（88年）→ 蛍光（90s）→ 漆黒（2010s）→ Y2K多色（今）
- フォントイメージ: Helvetica Neue Ultra Light × 等幅フォント（ターミナル感）

---

## スライド1（表紙 — タイトルスライド）
**タイトル**: 「服が、抵抗だった時代があった。」
**サブタイトル**: 「1988〜現在 — 30年のレイブファッション変遷」
**画像案**: 深い黒背景。中央に黄色いスマイリーフェイスのシンプルなシルエット。その周囲に小さなアーカイブ写真断片（バケットハット、黒いハーネス、Kappa、fluoro）をコラージュ状に散らす。全体的に古びたスキャン質感。
　→ フリー素材検索キーワード: `"rave crowd black and white archive 1990s"`
**レイアウト**: タイトル上部1/3、スマイリー中央大きく、サブタイトル下部小さく

## スライド2
**タイトル**: 「1988 — 解放の服」
**テキスト本文**:
```
ジャケット必須のクラブに、
スマイリーのTシャツで来た。

バケットハット。
ダンガリー。
首にウィッスル。

「おしゃれではなく、
踊るための服でいい」——それが革命だった。
```
**画像案**: 黄色い背景に黒でスマイリーフェイスをシンプルに描いたグラフィック。テキスト主体。右下に小さく「1988」の年号。
　→ フリー素材検索キーワード: `"yellow smiley face minimalist design vintage"`
**レイアウト**: テキスト左寄せ、画像要素は右側に

## スライド3
**タイトル**: 「1990〜1993 — ストリートがフロアに来た」
**テキスト本文**:
```
Hardcore。Jungle。Acid Techno。

KappaのトラックスーツでフロアへIN。
Nike Air Max 90、踏み鳴らす。
バケットハットを目深に。

「おしゃれ」を捨てたのではなく、
自分たちのストリートを
そのままフロアへ持ち込んだ。
```
**画像案**: グレーまたは濃紺背景。Kappa / Adidas風のストライプモチーフをパターン化したグラフィック。都市・コンクリートテクスチャ。
　→ フリー素材検索キーワード: `"90s sportswear streetwear concrete urban dark"`
**レイアウト**: テキスト中央揃え、背景パターンを薄く

---

## スライド4
**タイトル**: 「1994〜1999 — 二つのフロアの分岐」
**テキスト本文**:
```
UK Garageクラブ：
「スニーカー禁止。フード禁止。」
ドレスコードが戻ってきた。

でもフリーパーティの野原では、
パフジャケット。ウェリントンブーツ。
泥だらけのまま朝まで踊っていた。

同じ時代の、二つの答え。
```
**画像案**: 画面を縦に二分割。左は暗いクラブ照明でおしゃれな服の人影シルエット。右は野外フィールドの霧のなかの人影。中央に細い縦線。
　→ フリー素材検索キーワード: `"nightclub silhouette vs outdoor festival fog field"`
**レイアウト**: 二分割構成

---

## スライド5
**タイトル**: 「2000〜2009 — サイバーとグロー」
**テキスト本文**:
```
地下がメインストリームになった。

PVC。ゴーグル。グロースティック。
UV反応素材。LEDアクセサリー。

サイバーゴスが闇に浮かんだ。
Kandi（プラスチックビーズ）が腕を埋めた。

「見える」ことが武器になった夜。
```
**画像案**: 深紫〜黒のグラデーション背景。UV光で光るような蛍光グリーン・ピンクのアクセント。ゴーグルのシルエット。グロー効果。
　→ フリー素材検索キーワード: `"UV rave glow dark purple neon abstract"`
**レイアウト**: 縦長グラデーション背景にテキスト上部・グラフィック下部

## スライド6
**タイトル**: 「2010〜2019 — ベルリンの黒」
**テキスト本文**:
```
Berghainが、答えを変えた。

全身黒。
ハーネス。メッシュ。
ブランドロゴは見せない。

「目立つ」から「溶け込む」へ。
匿名であることが、最も強いスタイルになった。

フロアで撮影禁止——
だからこそ服は記憶にだけ残る。
```
**画像案**: 完全な黒背景。わずかに光る白のテキストのみ、または非常に薄い人影。最小限の構成。Berghainの印象そのまま。
　→ フリー素材検索キーワード: `"minimal dark black monochrome industrial abstract texture"`
**レイアウト**: 中央テキストのみ。余白を大きく取る。

---

## スライド7
**タイトル**: 「2020〜現在 — Y2Kが戻ってきた」
**テキスト本文**:
```
Kappaが戻ってきた。
バケットハットが戻ってきた。
90年代のバブルジャケットが戻ってきた。

でも今度は、TikTokで広がり、
Instagramで美しく撮られ、
古着屋で何万円もする。

皮肉じゃなく——それもまた
レイブが生んだ波紋のひとつ。
```
**画像案**: パステル×ネオンのY2K的カラー（ピンク、水色、黄緑）。透明PVCバッグ、バケットハットのイラスト的グラフィック。ポップで遊び心ある。
　→ フリー素材検索キーワード: `"Y2K aesthetic pastel neon fashion collage retro 2000s"`
**レイアウト**: ポップなカラーブロック。テキストは各色ブロックの上に

## スライド8（最終スライド）
**テキスト**: 「服を見れば、その夜フロアで何を求めていたかがわかる。自由。怒り。匿名。愛。ファッションはいつも、その時代のレイブの答えだった。」 + 「保存しておいて。また読みたくなるから。🖤」
**画像案**: 表紙と同じ黒背景＋スマイリー構成。ただしスマイリーをごく小さく右下に配置し、テキストに余白を持たせる。しめやかな終わり方。
**レイアウト**: テキスト中央。行間広め。静かに終わる。
