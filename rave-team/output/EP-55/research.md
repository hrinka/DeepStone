# EP-55 Research — Lee "Scratch" Perry

## Topic
Lee Scratch Perry：Black Ark Studio、ダブの発明、Bob Marleyとの関係、The Clashとの接続、英国音楽への影響

## Key Timeline

| 年 | 出来事 |
|---|---|
| 1936年3月28日 | Rainford Hugh Perry、ジャマイカ・ケンダル生まれ |
| 1950年代 | キングストンへ移住。Coxsone Doddのサウンドシステムで働き始める |
| 1965年 | "The Chicken Scratch"でデビュー、ニックネーム「Scratch」定着 |
| 1968年 | 自身のレーベル「Upsetter Records」設立 |
| 1969〜1971年 | Bob Marley & The Wailersをプロデュース（"Small Axe", "Duppy Conqueror", "Soul Rebel"） |
| 1973年 | キングストン・ワシントンガーデンズ地区の自宅裏にBlack Ark Studio建設 |
| 1976年 | Junior Murvin "Police and Thieves"（Black Ark産・UKシングルチャートで注目） |
| 1976年 | Max Romeo "War in a Babylon"（Black Ark産） |
| 1976年 | Upsetters "Super Ape"（Black Ark産） |
| 1977年 | The Congos "Heart of the Congos"（Black Ark産・後世の評価は最高峰） |
| 1977年 | The Clash "Complete Control"をロンドンでプロデュース |
| 1977年 | Bob Marley "Punky Reggae Party"をロンドンでプロデュース |
| 1979〜1983年 | Black Arkの壁を文字と絵で埋め尽くす。精神的変容期 |
| 1983年 | Black Ark Studio消失（火災）。電気事故説・Perry自身による放火説あり |
| 2021年8月29日 | ジャマイカ・ルーシアで死去、享年85 |

## Production Techniques（Black Ark時代）

- 4トラックレコーダーを多重録音で40トラック相当に使う
- エコーとディレイの実験的使用（「エコーは時間を伸ばす武器」）
- テープの逆回転・変速
- 環境音・ランダムな打撃音・鳥の声・水音を楽器として重ねる
- ボーカルの断片を繰り返し・逆再生・フィルタリング
- 「スタジオを楽器として扱う」哲学の実践者（King Tubbyは機器改造・Perryは空間操作）

## King Tubbyとの違い

| | King Tubby | Lee Scratch Perry |
|---|---|---|
| アプローチ | 機器改造・エンジニアリング的 | カオス・シャーマン的・精神的 |
| スタジオ | 18 Dromilly Avenue（他人の音源を操作） | Black Ark（自ら全制作） |
| 遺産 | DnB・Dubstep・Grime の技術的起源 | 実験音楽・UK dub・電子音楽の哲学的起源 |
| 死 | 1989年、自宅前で射殺 | 2021年、自然死85歳 |

## UK接続点

- "Police and Thieves"（1976）→ The Clashがデビューアルバムでカバー（1977）→ パンク×レゲエの出会いの証拠
- "Complete Control"（1977）をThe Clashのためにロンドンでプロデュース
- Adrian Sherwood（On-U Sound System）がPerryの技法を英国で発展
- Mad Professor（ブリクストン）がPerryの系譜継承
- Massive Attack、Portisheadなどブリストル勢がPerryの「霧の中の音」を継承
- King Tubby EP-54との連続性：「ダブは二人が同時に独立して発明した」
