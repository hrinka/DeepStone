episodes.md の確認結果:
- EP-39「Second Summer of Love 1988」でハシエンダに1行言及済み（「Manchester Haçienda（New Order売上運営）」）

## 収集した主要事実

### 時系列
| 年 | 出来事 |
|---|---|
| 1978 | Tony Wilson、Factory Records設立 |
| 1981 | ハシエンダ建設決定。Ben Kelly（設計）、Peter Saville（グラフィック）採用 |
| 1982.05.21 | ハシエンダ開業（FAC 51）。Bernard Manningが出演料を返却 |
| 1983 | New Order「Blue Monday」——史上最も売れた12インチシングル。ハシエンダ補填に使われる |
| 1986 | 「Nude」ナイト開始（Mike Pickering + Little Martin / のちGraeme Park） |
| 1987初 | 週7日満員に。MDMAがマンチェスターに流入開始 |
| 1988.07 | 「Hot」ナイト開始（Acid House特化） |
| 1988夏 | Madchesterムーブメント最高潮。Stone Roses、Happy Mondays、808 State |
| 1989.07.14 | Clare Leighton（16歳）、エクスタシー関連死——英国初 |
| 1990年代 | ギャング暴力、銃撃、財政圧迫が続く |
| 1997.06.15 | Spiritualized、最後のライブパフォーマンス |
| 1997.06.28 | 最後のクラブナイト「Freak」（Dave Haslam等）。閉館 |
| 2001 | 建物解体。備品競売。跡地に「The Haçienda Apartments」建設 |
| 2007 | Tony Wilson、腎臓癌で死去 |

### 建設コスト詳細
- 当初予算: £70,000（約1,400万円）
- 実際の建設費: £344,000（約7,000万円）
- ニューオーダー出資分: £100,000（約2,000万円）
- 初年度赤字: £300,000（約6,000万円）
- 累積負債ピーク: £1,000,000（約2億円）

### Charlotte R1nR1n アングル
- 「音楽のために作られたお金が、場所のために消えた」という逆説
- 「文化は箱に宿る——でも箱はいつか壊れる」というメッセージ
- 高級マンション化というエピローグの皮肉さ
- Factory Recordsの「アーティストが所有する」哲学との矛盾（最終的にクラブがアーティストを食い尽くした）
