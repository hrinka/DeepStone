## スライド2：出会いは倉庫だった
**テキスト**（大きく）:
```
1990年。
エセックス、ブレインツリー。
The Barn というレイブクラブ。

キース・フリントは
ただ踊っていた。
```
**サブテキスト（小）**: ライム・ハウレットのミックステープを受け取ったフリントは翌日戻ってきた。「お前の曲を、俺が踊ってやる」と。
**画像案**: 夜の倉庫の外観。入り口に人影がある。蛍光灯の光が一本漏れている。1990年代の雰囲気。
　→ フリー素材検索キーワード: `"warehouse rave entrance night 90s urban UK"`
**レイアウト**: テキスト左寄せ・縦積み。背景はほぼ黒。

## スライド3：政府が音楽を犯罪にした
**テキスト**（大きく）:
```
1994年。
イギリス政府は「反復するビート」を
犯罪にした。

ハウレットは怒った。
```
**サブテキスト（小）**: 「Music for the Jilted Generation」は刑事司法法（CJA）への怒りで書かれた。明るいレイブの色を全部捨て、重く、暗く、工業的な音に変えた。
**画像案**: 新聞の切り抜き風コラージュ。「BANNED」の赤スタンプ。立法文書と踊るシルエットが対比する構図。
　→ フリー素材検索キーワード: `"protest banner legislation paper dark collage rave ban"`
**レイアウト**: 中央揃え。「犯罪」の文字だけを赤`#C8001A`で。

## スライド4：ダンサーが、声を持った
**テキスト**（大きく）:
```
1996年。

フリントはダンサーを辞めた。
フロントマンになった。

「Firestarter」
UK シングル1位。
```
**サブテキスト（小）**: MTVが放送禁止にしようとした。それでも流れた。スパイクヘアとツインテールのその顔は、UK レイブが生んだ最初の本当のアイコンになった。
**画像案**: コンクリートの壁に影が一人。スパイク状のシルエット。顔は映らない。逆光と煙。
　→ フリー素材検索キーワード: `"punk silhouette backlight smoke stage dark portrait"`
**レイアウト**: シルエット右寄せ。テキスト左。「Firestarter」を赤で。

## スライド5：世界を制した一枚
**テキスト**（大きく）:
```
1997年6月30日。
「Fat of the Land」発売。

初週：317,000枚。
20カ国で1位。

最速セールスの
ダンスアルバム。
```
**サブテキスト（小）**: エセックスの倉庫から始まった音が、アメリカのビルボード200も制した。彼らはダンスバンドではなく、武装した何かになっていた。
**画像案**: アルバムアートワーク風の幾何学的グラフィック。黒と赤。数字「317,000」が画面を横断するタイポグラフィデザイン。
　→ フリー素材検索キーワード: `"bold typography album cover black red minimal number graphic"`
**レイアウト**: テキスト中央。数字は大きく背景に透かし。

## スライド6：パンクとレイブが融合した
**テキスト**（大きく）:
```
彼らはレイブバンドじゃなかった。
テクノバンドでもなかった。

パンクとレイブが
爆発したもの。

それが
The Prodigy だった。
```
**サブテキスト（小）**: Maxim（MC）、キース・フリント（ボーカル）、ライム・ハウレット（プロデューサー）。3人の役割が重なった瞬間、新しい何かが生まれた。既存のジャンルが溶けていた。
**画像案**: 電流のような光の線が画面を縦横に走る。人物はいない。純粋なエネルギーだけが可視化されたような画面。
　→ フリー素材検索キーワード: `"electric light lines dark abstract energy explode"`
**レイアウト**: テキスト中央。「パンクとレイブが爆発したもの」だけ赤で強調。

## スライド7：炎は、消えた
**テキスト**（大きく）:
```
2019年3月4日。

エセックス。

キース・フリント、
49歳。
```
**サブテキスト（小）**: ライム・ハウレットはInstagramにこう書いた。「彼は自らの命を絶った。」—— その後、ハックニーの壁に彼の顔が描かれた。1990年に初めてライブを行ったFour Aces Clubの近く。炎のシルエットが、今も壁に生きている。
**画像案**: 壁画風グラフィック。荒れたコンクリートの壁に、一本の赤い炎のシルエット。暗い夜。街灯の光だけ。
　→ フリー素材検索キーワード: `"street art mural wall graffiti flame red night urban hackney"`
**レイアウト**: テキスト左下に小さく。中央に炎のビジュアル。沈黙のような余白を保つ。
