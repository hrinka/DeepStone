# 開催SOP

毎回このリストを複製して潰す。**考える対象を減らすためのもの**。

## 2ヶ月前

- [ ] 定例会で日程・ゲスト・テーマを決定 → 議事録（`ops/minutes/`）
- [ ] 会場押さえ
- [ ] ゲストDJ打診（条件・ギャラ・時間・**MIX収録の許諾を同時に取る**）

## 1ヶ月前

- [ ] ゲスト確定 → プロフィール文と写真を受領（**英語プロフィールも依頼**）
- [ ] フライヤー制作 → 3人確認
- [ ] タイムテーブル案
- [ ] [[budget]] 見込みを立てる

## 3週間前 — 告知開始

- [ ] Instagram / X で告知第1弾（フライヤー + ラインナップ）
- [ ] イベントページ（あれば）作成
- [ ] ゲストに告知素材を送る（**本人にシェアしてもらうのが最も効く**）

## 1週間前

- [ ] 告知第2弾 + ゲスト紹介投稿
- [ ] タイムテーブル確定 → 出演者へ共有
- [ ] **機材確認**：REC機材、録音メディア、カメラ、電源、変換ケーブル
- [ ] 当日の役割分担を確認（誰がREC、誰が撮影、誰が受付）

## 前日

- [ ] 前日告知
- [ ] REC機材の**動作テスト**（本番で初めて触らない）
- [ ] カメラのバッテリー・SDカード

## 当日

- [ ] 開場前：REC設定確認、レベル確認
- [ ] **ゲストのセットを録る**（[[sop-mix]]）
- [ ] **プレイ中写真を撮る**（ジャケ用。1:1で使える引きの構図を必ず含める）
- [ ] フロアの引きの絵も撮る（人物特定できない角度）
- [ ] ゲストにMIX公開時期を伝える

## 翌日〜3日以内

- [ ] REC音源をバックアップ（**2ヶ所**）
- [ ] 写真を `_attachments/` へ
- [ ] 開催ログを書く（`_templates/subcurrent-edition.md`）
- [ ] ゲストへお礼

## 1週間以内

- [ ] 記録投稿
- [ ] [[budget]] 実績を記入
- [ ] [[guest-djs]] にエントリ追加・更新
- [ ] 良かった点／詰まった点を1行ずつ、次回SOPに反映
