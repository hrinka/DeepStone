# 年間サイクル

## 基本リズム

| 月 | 内容 |
|---|---|
| **偶数月** | **パーティー開催** ＋ MIX更新（第二水曜） |
| **奇数月** | 開催なし。MIXのUP、随時連絡・打ち合わせ |

> [!todo] 要確認
> 「偶数月第二水曜日に更新」と「開催しない月にはMIXのUP」が両立しない。
> **案：偶数月＝GUEST MIX／奇数月＝HOST MIX・アーカイブ** にすれば毎月1本になり、間が空かない。
> → [[mix-distribution]] 参照。次の定例会で確定する。

## 1サイクル（2ヶ月）の標準進行

開催月を M とする。

| タイミング | やること | 担当 |
|---|---|---|
| M-2 月内 | **定例会**：次回ゲスト決定、日程確定、テーマ確認 | 全員 |
| M-2 月内 | ゲストDJ打診・確定 | ブッキング |
| M-1 月上旬 | フライヤー制作（[[visual-language]] の型を使う） | ビジュアル |
| M-1 月中旬 | **告知開始**（3週前）。ゲスト紹介投稿 | SNS |
| M 第2水曜 | **MIX公開** ＋ 切り抜き投稿 | コンテンツ |
| M 開催1週前 | 告知（1週前）、タイムテーブル確定、機材確認 | 全員 |
| M 前日 | 前日告知 | SNS |
| **M 開催日** | 当日運営。**REC回す／プレイ中写真を撮る** | 全員 |
| M +3日 | 開催ログを書く（`_templates/subcurrent-edition.md`） | 全員 |
| M +1週 | 記録投稿。ゲストへお礼＋MIX素材の確認 | SNS / コンテンツ |
| M+1 月 | MIXのEdit → 次サイクルへ | コンテンツ |
