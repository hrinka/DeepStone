# MIX配信SOP

戦略は [[mix-distribution]]。ここは**手順だけ**。

## 0. 事前（打診の時点で）

- [ ] ゲストDJに**録音・公開の許諾**を取る（打診メールに最初から入れる）
- [ ] 公開時期を伝える（例：開催の翌々月 第二水曜）

## 1. REC（当日）

- [ ] ミキサーのMASTER OUT から録る（フロアのマイク録りは避ける）
- [ ] **-6dB 前後**でピークを取る。歪ませない
- [ ] セット開始の1分前から回す（頭切れ防止）
- [ ] 終了後、**その場でファイルを確認**（無音・欠落がないか）
- [ ] 2ヶ所にバックアップ

## 2. Edit

- [ ] 頭と尻をトリム（フェードイン/アウト 2-3秒）
- [ ] MCや場内アナウンスの扱いを決める（残す方が場の空気が伝わることも多い）
- [ ] **ノーマライズ / 軽いリミッター**（-1.0dBTP、LUFS -9〜-11 目安）
- [ ] 書き出し：`WAV` でマスター保存 → `MP3 320kbps` でアップ用
- [ ] ファイル名：`SubCurrent_Transmission_001_ArtistName.mp3`

## 3. ジャケット

- [ ] 当日のプレイ中写真から1枚選ぶ
- [ ] **1:1、3000×3000px 以上**
- [ ] サイケ層の型を重ねる（[[visual-language]]）— モアレ or 歪んだリング
- [ ] ロゴ配置は固定位置（回ごとに変えない）
- [ ] `_attachments/subcurrent/` に保存

## 4. 説明文（テンプレ）

```
SubCurrent Transmission 001 — <ARTIST NAME>
Recorded live at SubCurrent Vol.<NN>, <DATE>, <VENUE>, Tokyo.

<1-2 sentences about the artist / the set. EN>

---
SubCurrent
Drift below the surface.
A deep bass party built on minimal, dub, druidstep, ambient and leftfield —
low frequency as a place, not a genre.

Hosted by Rt3mis / DJ SolaNino / DJ KCT
<links>

#druidstep #dubstep #soundsystem #bassmusic #leftfield #minimaldub #tokyo
```

JP版を下に併記する。

## 5. 公開（偶数月 第二水曜）

- [ ] SoundCloud にアップ（公開時刻は **20:00 前後**を標準に）
- [ ] プレイリスト `SubCurrent Transmissions` に追加
- [ ] Instagram / X で告知（切り抜き縦動画つき）
- [ ] **ゲスト本人に公開URLを送り、シェアを依頼**
- [ ] [[archive-vol01-16]] / 各回ログにURLを記入

## 6. 1週間後

- [ ] 再生数・国別統計を [[kpi]] の観点で確認
- [ ] 反応が良かった切り抜きを記録（次回の作り方に反映）
