# 議事録

定例会（偶数月）の記録をここに貯める。

## 命名

```
YYYY-MM-DD 定例会.md
```

## 作り方

`_templates/subcurrent-minutes.md` から生成する。

## 書くときの原則

- **決めたことは「決定事項・決めた人・期限」の3点セットで書く。** どれかが欠けると実行されない
- 決まらなかったことも「未決」として残す。次回そこから始められる
- 議論の経緯より**結論と理由**を残す。理由が残っていれば後から覆せる
- 定例会の外で決まったことも、事後に1行追記する
