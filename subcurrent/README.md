# SubCurrent

定期 bass music パーティー。3人共催。**Vol.16 まで開催済み**（2026-08 時点）。

> Drift below the surface.
> A deep bass party built on minimal, dub, druidstep, ambient and leftfield —
> **low frequency as a place, not a genre.**

このフォルダは SubCurrent の**運用と思考のリポジトリ**。
蒸留された概念は `wiki/` 側（[[SubCurrent]] = `wiki/projects/SubCurrent.md`）に置き、
ここには**生きた運用ログ・議事録・戦略メモ**を貯める。

## いま効く順（優先度）

1. **MIX配信の仕組みを回す** — 16回分の資産が未活用。ここが最大の機会損失
2. **ビジュアル言語の確定** — ロゴ＋サイケ層。全SNS施策の前提になる
3. **ゲストDJ台帳の整備** — 16回分の関係を資産化する（[[guest-djs]]）
4. **英語での一貫した自己紹介** — 海外に出る前の最低条件（[[concept]] EN版）
