## 役割の設計案

3人体制は**役割を決めないと全部を3人でやることになり、全部が遅れる**。
オーナー（最終決定者）を1機能につき1人置く。実作業は分担してよい。

| 機能 | オーナー | 内容 |
|---|---|---|
| ブッキング | | ゲストDJ選定・打診・条件交渉 |
| 会場・当日運営 | | 会場折衝、機材、タイムテーブル、当日進行 |
| ビジュアル / 制作 | | ロゴ、フライヤー、背景画像、グッズ |
| コンテンツ / 配信 | | MIXのREC・Edit・アップ、写真、SoundCloud |
| SNS / 告知 | | 投稿カレンダー、文面、リーチ |
| 会計 | | 収支、SoundCloud Pro 等の固定費 |
| 海外・対外 | | 英語での対外窓口、ブッキング打診 |

## 決め方のルール（案）

- **定例会で決めたことは議事録に残す**（`ops/minutes/`）。決めた人・期限・次アクションをセットで
- 定例会外の判断は**オーナーが単独で決めてよい**。事後に議事録へ1行
- コンセプト・ビジュアルの根幹に関わる変更のみ3人合意
