# ポジショニング

## 一行

**日本のベースミュージックシーンにおいて、「儀式的・有機的なサイケデリア」を軸に低音を扱う、ほぼ唯一のパーティー。**

## 座標

2軸で置くと立ち位置がはっきりする。

```
                  スペクタクル（大箱・EDM的）
                            ↑
   ケミカル/多幸的 ←────────┼────────→ 儀式的/有機的
                            ↓
                  没入（サウンドシステム的）
```

SubCurrent は **右下**（儀式的 × 没入）。
- **左上**：一般的なEDM/ベースイベント。蛍光色、ドロップ、フェス文脈
- **左下**：サイケトランス/ゴア系。ケミカルな語彙のサイケ
- **右上**：アート寄りのインスタレーション。踊れないことが多い
- **右下**：ダブ〜サウンドシステム文脈の系譜（DMZ、FWD>>、Kingston Dub Club など）。SubCurrent はここに、**druidstep という日本ではまだ空いている入口**から入る

## 参照系（勝手に系譜を名乗る、ではなく「同じ問いを扱っている」先行例）

| 名前 | 何を学ぶか |
|---|---|
| DMZ（Brixton） | 「Come meditate on bass weight」— 低音を瞑想の対象として言語化した |
| FWD>>（Plastic People） | 暗さと余白でフロアを作った。音以外を削る設計 |
| Kingston Dub Club | 週次で場を維持し続けることそのものが文化になる |
| Berghain | 空間と規範がサウンドと同じくらい体験を決める |

→ vault 内の既存リサーチ：`wiki/sources/rave/` の EP-68 / EP-66 / EP-43 など

## 差別化の言い方（ブッキング・取材で使う）

- ❌「深いベースミュージックのパーティーです」→ 誰でも言える
- ⭕「**低音を "ジャンル" ではなく "場所" として扱う**パーティーです。サイケデリックを掲げていますが、ケミカルな方ではなく、反復と余白と空間の鳴らし方——druidstep が指す儀式的な方です」
