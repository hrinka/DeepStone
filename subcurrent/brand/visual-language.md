# ビジュアル言語

原典：Google Docs「SubCurrent_20260822 — サイケデリック層」

## 大原則

> **サイケは「足す」のではなく「重ねる」。**

サイケデリックと聞いて一般にイメージされるのは、蛍光色・溶けた文字・フラクタル・目玉——
**ケミカルでレイヴ寄りの語彙**。それを足すと、いま出来ている「深く静かな水中」のトーンが即座に壊れる。

druidstep 側に寄せるなら、必要なのは **儀式的・有機的なサイケデリア**。
森、石、菌類、年輪、月、水面。トリップの語彙ではなく **自然が勝手にやっている反復と幾何** の語彙。

そして重要なのは、**いま持っている「円」からすべて派生できる**こと。
新しい要素を持ち込む必要がない。円を2つ重ねればモアレになり、円を歪ませれば波面になり、
円を不均等にすれば年輪になる。**ロゴの言語を保ったままサイケになれる。**

---

## 採用候補（推し5案）

### 1｜モアレ ★
同じリング系を2つ、少しずらして重ねるだけ。干渉縞が生まれ、見ていると視覚が揺れる。
**追加した要素はゼロ**なのに一番サイケになる。既存の資産だけで完結するのが強い。

### 2｜サイマティクス ★
音が物質に描く図形。振動する板の上で砂が節線に集まる、あの現象。
**低音＝物理現象**であることの証明そのもの。サイケでありながら理屈が完全に通っていて、
ケミカル感がゼロなのに強烈に効く。

### 3｜歪んだリング ★
低音の波面でリングが撓む。完全な円ではなく、5次と3次の波でわずかに歪ませる。
**「円が低音で曲げられている」**という理屈が通っていて、しかも有機的。動かすと最高に効く。

### 4｜年輪 ★
同心円のまま「森」になる。不均等な間隔、微妙な揺らぎ、時々走る裂け目。
**ドルイド側の顔**で、ケミカルさが一切ない。同心円という構造は保たれたまま、意味だけが水から森へ移る。

### 8｜ストーンサークル ★
儀式の幾何。平面図で見た環状列石。同心円＋放射線という、既存の言語とそのまま繋がる構造。
至点のアライメント線を入れると一気に「儀式」になる。

## 使い分け

| 用途 | 何を使うか |
|---|---|
| **ロゴ本体** | **いまのまま。サイケを入れない** |
| フライヤー背景 | サイケ層（モアレ／歪んだリング／年輪） |
| 回替わりの表情 | パレットの土の色を1色ずつ入れ替える |
| VJ・動画 | サイマティクス（BPMで図形が変わる） |
| グッズ | ストーンサークル or 年輪（単色で強い） |

> **ロゴ本体にサイケを入れないのが肝。**
> ロゴは静かなまま、周りが揺れる。そのコントラストが「深く潜っている」感じを作る。
> 全部揺れると、ただの騒がしいフライヤーになる。

## Mark System v1（2026-08-24）

**採用方向：歪んだリング（案3）。** ここから全部を派生させる方針で確定。

すべてのマークが同じ一行の式から出ている：

```
r(θ) = R (1 + a₃·sin(3θ + φ₃) + a₅·sin(5θ + φ₅))
```

変えているのは**振幅・線の太さ・見せる範囲**だけ。だから並べても family に見え、
あとから増やしても言語が崩れない。

### 歪んだリング ファミリー（8案）

| コード | 名前 | 性格 |
|---|---|---|
| A1 | 基本 | 外へ行くほど強く曲がり、線は細くなる |
| A2 | ソナー | 右へ開く。Cから広がる原案とそのまま接続できる |
| A3 | 太細 | 太線と細線の交互。「heavy だけど繊細」を一枚で満たす |
| A4 | 塗り抜き | 線ではなく面。小サイズでも潰れない＝SNSアイコン向き |
| A5 | 単環 | 極小用。20mm でも形が残る |
| A6 | ドリフト | 中心が流される。水流のニュアンス |
| A7 | 溶解 | 外側が破線で解けていく。動画・VJ向き |
| A8 | ×モアレ | 2セットの干渉。見ていると視覚が揺れる |

その他のサイケ層（B1 モアレ／C1 年輪／D1 ストーンサークル／E1 サイマティクス／
F1 リサージュ／G1 菌糸／H1 対数螺旋）はロゴ本体には使わず、
**フライヤー背景・VJ・グッズ**で回す。

### ロックアップ

- **L1 横組み** — マーク＋ワードマーク。Web・名刺・メール署名の標準形
- **L2 Cから広がる** — 原案Bの発展形。波紋はCを中心に立ち、文字は白ヌキで前に出る
- **L3 縦組み** — マーク上・ワードマーク下

### ステッカー（Sub / Current 縦積み）

2行の幅を**光学的に揃えている**（Sub をトラッキングで伸ばして Current と同幅に）。
文字数の違う2語を積むときの定石で、これがあるだけで「作られた形」に見える。

| コード | 形 | メモ |
|---|---|---|
| S1 | 円形・リング背景 | 落ち着いた標準版。40mm 以上で使う |
| S2 | 円形・塗り抜き | 遠目・小サイズでの視認性が最も高い |
| **S3** | **ダイカット・歪んだ輪郭** | **輪郭そのものが歪んだリング。形で覚えられる＝一番強い** |
| S4 | 角丸スクエア | 機材・ケース向き |
| S5 | 単環・極小用 | 25mm でも読める |
| S6 | 縦長 | ラップトップの縁・機材の隙間に |
| S7 | 1色・シルク用 | 白地に1色。転写・シルクスクリーン入稿用 |

大文字版（SUB / CURRENT）は camel case より硬く匿名的。機材貼り・モノトーングッズ向き。

> **まず1種類作るなら S3 を60mm。** 輪郭が歪んだリングそのものなので、
> 貼られた状態で最も「これは SubCurrent だ」と分かる。

## Mark System v2（2026-08-24）— フォント確定とサイケ層の拡張

### フォント：Michroma / Orbitron

- **Michroma 400** — 字面が広くモノライン。間延びさせると一気に「深いところ」に見える
- **Orbitron 400〜900** — ウェイトがあるので**ワードマークの中で強弱を作れる**

どちらも Google Fonts。SVG 内の文字はアウトライン化済みなのでフォント無しでも開ける。

### 縦積みの修正

前回の違和感の原因は、**Sub を無理にトラッキングで伸ばして Current と同幅にしていた**こと。
字間が空きすぎて「S U B」という別の語に見えていた。

> **文字数の違う2語は、幅を揃えず、軸を揃える。**

- **左寄せ** — 左の軸が通る。硬く、機材に貼った時に強い
- **中央・自然幅** — 塊としてまとまる。円形ステッカー向き

表記は **SUB / CURRENT の大文字・スペースなし**に統一。

## Mark System v3（2026-08-24）— ドルイド／サイケデリックへ振り直し

### 判断

v2 は**ポップすぎた**。サウンドシステムや波形は正確だが、
角丸・均等・明快さが重なると「ガジェットのアイコン」に見える。
druidstep を掲げている以上、**儀式と自然の語彙**に寄せるべき。

> **ポップさを抜く4つの手**
> 1. **角丸をやめる** — 護符・盾・不定形の輪郭にする
> 2. **ハッチングを入れる** — 線の密度で明暗を作ると手の跡が出る
> 3. **不揃いにする** — 光条・年輪・石の間隔を揃えない
> 4. **意味ありげな線を足す** — 至点のアライメント、月相、目盛り

### 表記：SubCurrent（小文字混じり）を追加

Michroma の小文字は**大文字より柔らかく、少し古い**感じが出る。
全部大文字は現代的・工業的になるので、儀式寄りに振るなら小文字混じりの方が合う。
大文字版（v2）は硬く匿名的で、機材・モノトーングッズ向けとして残す。

### 儀式・ドルイド系マーク 8案

| コード | 名前 | メモ |
|---|---|---|
| R1 | 月相環 | 8つの月が環をなす。ドルイドの暦 |
| **R2** | **密なモアレ場** | 細リング46本×3セット。**見ていると視覚が振動する。要素は何も足していない** |
| **R3** | **彫版の同心円** | 木版・銅版のハッチング。**「機械で描いた」感じを消す一番効く手** |
| R4 | オウロボロス | 太さの変わる歪んだ環。終わらない輪 |
| R5 | 根のマンダラ | 放射する根。左右対称で儀式的 |
| R6 | 儀式の太陽 | 不揃いの光条。石に彫られた太陽 |
| R7 | ポータル | 奥へ落ちていく環。深く潜る感覚そのもの |
| **R8** | **角の環** | 角と三日月＝ケルヌンノス。**druidstep という語に最も近い** |

### 横組み（小文字混じり）7案

V1 ポータル＋Michroma（推し）／ V2 罫線で挟む／ V3 儀式の太陽＋Orbitron／
**V4 角の環＋Michroma（最もドルイド寄り）**／ V5 モアレ場／ V6 オウロボロス／
V7 Sub=Black・Current=Regular

### ステッカー 10案

**U1 印（円環に文字＋儀式の太陽）が推し。**
円環に文字が回っているだけで、貼られた瞬間に「何かの団体の印」に読まれる。

U2 印・月相環／ **U3 ダイカット・彫版**／ U4 ポータル／ U5 角の環／ U6 オウロボロス／
**U7 スクエア・モアレ場（T6 の直し）**／ **U8 タリスマン（T5 の直し）**／
U9 1色シルク用の印／ U10 根のマンダラ

#### T5 → U8
角丸の箱にスピーカーが並ぶと、どうしてもガジェットのアイコンに見える。
**下端を尖らせて護符の形にし、彫版のリングと月に差し替えた**だけで、同じ縦長でも意味が変わる。

#### T6 → U7
文字が絵の真ん中に浮いていた。**下1/3に落として地の帯を敷き、上を密なモアレ場に。**
文字が座る場所ができ、上半分は思い切り揺らせる。

**25mm で生き残るのは U3 と U7** のみ。
