# MIX配信戦略

## 現状

**16回開催して、配信資産がほぼゼロ。** ここが最大の機会損失。
パーティーは一夜で消えるが、MIXは残って働き続ける。海外に出るなら**音源が名刺**になる。

## 決まっていること

| 項目 | 内容 |
|---|---|
| プラットフォーム | SoundCloud Pro（**¥9,900/year**） |
| 更新タイミング | **偶数月・第二水曜日** |
| HOST DJ | 3名それぞれ1本ずつ掲載（＝初回3本） |
| GUEST DJ | 毎回1人をREC → Edit → feature |
| ジャケット | **プレイ中の写真**を毎回撮影して使う |

> [!todo] 要確認
> 送られた情報に「定例会：偶数月（開催しない月にはMIXのUP）」と「MIX更新：偶数月第二水曜日」の両方があり、
> **奇数月にも上げるのか / 偶数月だけか**が確定していない。次の定例会で決める。
> → 案：**偶数月＝GUEST MIX（その回の記録）／奇数月＝HOST MIX or アーカイブ**。これなら毎月1本のリズムになり、間が空かない。

## なぜ SoundCloud なのか（この判断のログ）

- ベースミュージック / サウンドシステム文脈の**一次流通がいまだに SoundCloud** である
- 海外のブッカー・オーガナイザーが最初に見る場所
- Pro にするとアップ時間無制限＋再生統計が取れる（[[kpi]] の入力になる）

ただし **SoundCloud を「置き場」にしない**。
YouTube / Mixcloud はミラー、Instagram / TikTok は**切り抜きの入口**として使う（[[sns]]）。

## シリーズ設計

配信に**名前と番号**をつける。単発のアップロードは流れて消えるが、シリーズは追われる。

```
SubCurrent Transmission 001 — <DJ NAME>
```

- `Transmission` = 送信・伝達。地下から送り出すニュアンスがコンセプトと合う
- 3桁番号で「長く続く前提」を最初から示す
- 説明文には**毎回同じ定型ブロック**（[[concept]] のEN短縮版＋パーティー情報）を入れる → どの1本から入っても全体像が伝わる

代替案：`SubCurrent Depth 001` / `Below the Surface 001` / 単に `SubCurrent 001`
→ 次の定例会で決定

## 1本あたりの成果物（契約）

MIX 1本につき、以下4点セット。これが揃って初めて「上げた」とみなす。

```
1. 音源      — Edit済み、ノーマライズ済み、60-90分
2. ジャケ画像 — プレイ中写真 + サイケ層の型（1:1 / 3000px以上）
3. 説明文     — EN + JP、定型ブロック + そのDJの紹介
4. 切り抜き   — 60秒×1-2本（Instagram / TikTok用の縦動画）
```

手順は [[sop-mix]]。

## 効かせ方

- **GUEST DJ本人に必ずシェアしてもらう。** これが最大の拡散経路であり、同時に**関係の継続**になる
- アップした日にパーティーの告知も重ねる（配信と告知を同じ波に乗せる）
- **タグ運用**：`#druidstep` `#dubstep` `#soundsystem` `#leftfield` `#bassmusic` `#minimaldub`
  - `#druidstep` は母数が小さい＝**取りに行けば上位に居座れる**。意識的に使う
