# グローバル展開

## 前提の整理

「世界へ進出したい」を分解すると、実は3つの別の目標が混ざっている。
**混ぜたまま進めると全部が中途半端になる**ので、分けて考える。

1. **SubCurrent（パーティー）が海外で認知される**
2. **Rt3mis（自分）が DJ / singer として海外でブッキングされる**
3. **日本のこのシーンごと、外から見つけられる状態になる**

3つは相互に効くが、**入口は 1 と 2 のどちらかを先に決めた方がいい**。
現実的には **「2 を 1 で支える」**——パーティーという継続的な実体があることが、
個人のDJとしての説得力になる。海外のブッカーは「単発のDJ」より「場を持っている人」を信用する。

## 海外から見つけられる条件（最低ライン）

いま満たしていないものにチェックを入れて潰していく。

- [ ] **英語のプロフィールが存在する**（パーティー / 各DJ）
- [ ] **聴ける音源が5本以上ある**（[[mix-distribution]]）
- [ ] **視覚的に一貫している**（[[visual-language]]）
- [ ] **どこの誰か分かる** — 都市名を明記する。"Tokyo" / "Japan" は検索とブッキングの両方で効く
- [ ] **連絡先がある** — booking用のメールアドレス1つ
- [ ] **英語圏の文脈語で説明できる** — `dubstep` `soundsystem` `leftfield bass` `druidstep`

## 日本発であることの扱い方

**「日本の」を売りにするか、しないか。** ここは意識的に決める。

- ❌ 安易な和風意匠（漢字ロゴ、鳥居、和柄）— 海外では消費されやすく、深い方の人には軽く見える
- ⭕ **感覚のレベルで日本的であること** — 余白、静けさ、儀式性、自然物の幾何
  → これは既に [[visual-language]] のサイケ層（年輪 / ストーンサークル / サイマティクス）と一致している
- ⭕ 「Tokyo」「Japan」は**事実として明記**する。文脈としては使うが、意匠としては使わない

つまり **"Japanese party" ではなく "a party that happens to be in Japan, and sounds like it"**。

## 現実的な最初の一歩（コストの低い順）

1. **海外のミックスシリーズにゲストミックスを送る** — 費用ゼロ、断られても失うものがない
2. **来日中の海外アーティストをゲストに呼ぶ** — 向こうのSNSに SubCurrent の名前が載る
3. **海外パーティーとのオンライン共催 / 交換MIX** — 姉妹パーティー関係の種
4. **自分が渡航して1回出る** — 費用は高いが、関係は現地でしか作れない
   → 目的地の候補は [[targets-global]]

## 時間軸

Phase 1-2（[[roadmap]]）で足元を固めるまで、海外は**種まきだけ**でいい。
音源も見た目も整わないうちに海外に打診すると、**一度きりの第一印象を安く使ってしまう**。
逆に、資産が整っていれば打診は一気に効く。急ぐ理由はない。
