# SNS運用戦略

## 原則

**告知だけのアカウントは、告知の時しか見られない。**
SubCurrent のSNSは「イベント告知板」ではなく、**この音楽の世界観に触れられる場所**にする。
そうすると、開催がない月も生き続ける。

## 役割分担

| 媒体 | 役割 | 頻度 |
|---|---|---|
| **Instagram** | 本拠地。世界観 + 告知 + アーカイブ | 週1-2 |
| **SoundCloud** | 音の本体（[[mix-distribution]]） | 月1 |
| **X / Twitter** | 当日の実況、シーン内の会話 | 随時 |
| TikTok / Reels | 切り抜きによる新規流入 | MIX更新に合わせて |
| （検討）Bandcamp | 音源販売・投げ銭が必要になったら | — |

## コンテンツの型（回すためのフォーマット化）

毎回ゼロから考えると続かない。**5つの型**を回す。

| 型 | 内容 | いつ |
|---|---|---|
| **A. 告知** | フライヤー + ラインナップ | 開催3週前 / 1週前 / 前日 |
| **B. 音** | MIX公開告知 + 切り抜き縦動画 | 第二水曜 |
| **C. 記録** | 当日のフロア写真（人が写らない引きの絵も） | 開催後1週以内 |
| **D. 言葉** | コンセプトの断片・ジャンル解説・引用（サイケ層の背景画像に載せる） | 月1-2、空いた週に |
| **E. 人** | ゲストDJ紹介、共催3人のセレクト | 告知期間中 |

**D（言葉）が効く。** 「druidstep とは何か」「なぜ低音は "感じる" のか」といった短い解説は、
このパーティーが**考えていること**を示す。海外の人が偶然見つけたときに刺さるのもここ。

## ビジュアルの統一

- 背景画像・ロゴは [[visual-language]] / [[assets]] に集約
- **ロゴ本体にサイケを入れない。** ロゴは静かなまま、周りが揺れる
- 回替わりの表情は**パレットの土の色を1色ずつ入れ替える**ことで作る（型は変えない）

## 言語

**JP → EN の順で併記**を標準にする。
海外を見るなら、いま英語を書き始めるしかない。翻訳ではなく、**最初から短い英語で書く**。
[[concept]] の共有語彙をそのまま使えば、毎回考えなくていい。

## やらないこと

- フォロワー数を目的にしない
- トレンド音源に乗せた文脈のないリール（世界観が壊れる）
- 過剰な投稿（週3以上は3人体制では破綻する）

## 投稿カレンダー（偶数月サイクル）

| 週 | 内容 |
|---|---|
| 偶数月 第1週 | D. 言葉 / E. 人（ゲスト発表） |
| 偶数月 第2週（水） | **B. MIX公開** |
| 偶数月 第3週 | A. 告知（1週前）+ E. 人 |
| 偶数月 第4週 | A. 前日告知 → **開催** → C. 記録 |
| 奇数月 | D. 言葉 ×2、C. アーカイブ再掲、B.（決定次第） |
