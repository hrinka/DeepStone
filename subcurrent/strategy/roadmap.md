# ロードマップ 2026-2028

目標：**日本のベースミュージックシーンで確固たるポジションを築き、そこから世界へ出る。**

前提として押さえておくこと：**16回やっている、というのは既に強い**。
問題は続けていないことではなく、**続けたことが外から見えないこと**。
だからフェーズ1は新しいことを始める話ではなく、**既にあるものを見える形にする**話になる。

---

## Phase 1｜資産化（2026下期 — Vol.17〜Vol.20 / 〜2027春）

> 合言葉：**「やったことを、存在する形にする」**

- [ ] **MIX配信を回し始める**（[[mix-distribution]] / [[sop-mix]]）
  - SoundCloud Pro 契約（¥9,900/year）
  - HOST DJ 3本を先に上げて棚を作る
  - 以降、毎サイクル GUEST 1本
- [ ] **ビジュアル言語の確定**（[[visual-language]]）
  - ロゴ確定 → ベクター納品
  - サイケ層（モアレ / 歪んだリング / 年輪）をフライヤー背景の型に
  - SNS背景画像・アイコンの統一
- [ ] **アーカイブの遡及**（[[archive-vol01-16]]）
  - 過去16回の日付・会場・出演者・写真の有無を埋める
  - 残っている写真・音源を集める
- [ ] **ゲストDJ台帳**（[[guest-djs]]）— 16回分の関係を一覧に
- [ ] **英語プロフィールの整備** — パーティー / 各DJ、共通フォーマットで

**このフェーズのゴール**：初見の人が SoundCloud か Instagram を5分見て「これは長くやっている、筋の通ったパーティーだ」と分かる状態。

---

## Phase 2｜到達（2027 — Vol.21〜）

> 合言葉：**「シーンの中で名指しされる」**

- [ ] **ゲストの質を一段上げる** — 国内の該当領域で名前が効く人を年2〜3組
- [ ] **他パーティーとの交換**（東京 / 大阪 / 名古屋など）— 出張 or 共催
- [ ] **メディア露出** — インタビュー、ゲストミックス寄稿、ラジオ
- [ ] **グッズ** — ステッカー / Tシャツ。ストーンサークル or 年輪の単色版
- [ ] **海外DJのゲスト招聘に1回挑戦** — 来日ツアー中の枠を取る形が現実的
- [ ] **英語圏メディアへの露出を1本**（ミックスシリーズ寄稿など）

**このフェーズのゴール**：「日本でこの音をやるなら SubCurrent」と、シーンの人が第三者に説明できる状態。

## Phase 3｜越境（2028 —）

> 合言葉：**「向こうから声がかかる」**

- [ ] **海外でのショーケース** — 1都市でいい。ロンドン / ベルリン / 東南アジア
- [ ] **レーベル or ミックスシリーズ** — パーティーを音源として輸出できる形に
- [ ] **海外パーティーとの姉妹提携**
- [ ] **自分自身のDJ / singer としての海外ブッキング**（パーティーと相互に効かせる）

→ 詳細は [[global]]

## 進め方の原則

1. **偶数月サイクルを壊さない。** 続いていること自体が最大の資産
2. **1サイクル＝1つの新しい試み。** 3人でやれる量を超えない
3. **やったことは必ず記録に残す。** 記録がないものは、無かったことになる
4. **数字は見るが、数字で判断しない。** [[kpi]] は健康診断であって目的ではない
