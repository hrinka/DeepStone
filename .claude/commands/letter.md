# /letter — 今朝のレターを書く

Rinka の今日のデイリーノートを用意し、**空の朝セクションだけ**を埋める。
07:08 JST のクラウドルーチンと同じロジック。ルーチンの前でも後でも取りこぼさないための手動版。

## 大原則

- **Rinka が書いたものには一切触らない。** 📝 日記 / 🔁 日課 / 🎯 今日のタスク は読むだけ
- **空のセクションだけ埋める。** 既に本文があるセクションは絶対に上書きしない
- **日記は `journal/YYYY-MM-DD.md`（フラット）。** `journal/YYYY-MM/` には作らない
  （`.obsidian/daily-notes.json` の `folder: "journal"` に合わせる。過去ログはサブフォルダに
  残っているが、読むだけ・新規は作らない）

---

## Step 1: 今日のノートを用意する

```bash
TODAY=$(TZ=Asia/Tokyo date '+%Y-%m-%d')   # Rinka は JST。実行環境が UTC だと1日ずれる
TODAY_FILE="journal/$TODAY.md"
ls "$TODAY_FILE" 2>/dev/null || echo "NOT_FOUND"
```

無ければ `_templates/daily-note.md` を Read し、`{{date:YYYY-MM-DD}}` を今日の日付に
置換して `$TODAY_FILE` に Write する。**テンプレートの内容はここに直書きしない**
——テンプレートを直したときに二重管理にならないよう、必ず読みに行く。

## Step 2: 前回の日記を特定する【昨日とは限らない】

日記は毎日書かれるとは限らない。ルーチンが生成しただけの「📝 日記が空のノート」を
掴むと返事が書けないので、**本文があるファイルまで遡る**。

```bash
TODAY=$(TZ=Asia/Tokyo date '+%Y-%m-%d')   # Rinka は JST。実行環境が UTC だと1日ずれる
find journal -name '20??-??-??.md' | sed 's|.*/||' | sort -r \
  | awk -v t="$TODAY.md" '$0 < t' | head -10
```

出た候補を新しい順に Read し、**`## 📝 日記` に本文が入っている最初の1件**を PREV とする。
（フラットとサブフォルダの両方に同名がありうる。`find journal -name '<候補>'` で実パスを引く）

PREV が見つからなければ Step 4 の宇宙天気・運勢と季節感からレターを書く。

## Step 3: 文脈を読む

- `Memory.md` — Rinka に関する事実の正典（根本ビジョン・大目標・現在の状況）
- `SOUL.md` — Claw の人格と返答スタイル
- `wiki/hot.md` — 直近の文脈

## Step 4: 🌌 宇宙天気 を埋める

4行すべて。各行は1文で簡潔に。

- **🌙 月** — 月相（新月/上弦/満月/下弦・何日目か）と月がいる星座
- **📜 暦** — 旧暦の日付・二十四節気・七十二候
- **🌀 マヤ暦** — KIN 番号と紋章・音
- **🌊 流れ** — `wiki/meta/宇宙天気-今の流れ.md` の「今の流れ」から1行転記

`wiki/meta/宇宙天気-今の流れ.md` の `next_review` を今日が過ぎている、または新月・満月・
節気・ゲート系の節目をまたいだ場合は、**先にそのファイルを更新**してから転記する
（LIVING ドキュメント。追記せず書き換える）。

月・暦は WebSearch で取得する。**マヤ暦の KIN は検索しない**——個人サイトに誤りが多いので、
[[マヤ暦-KIN計算]] の手順で計算し、同ページの検算（年の紋章は4種類しか出ない）を通す。

## Step 5: 🔮 今日の運勢 を埋める

Rinka 個人の運勢。3軸を各1〜2文。一般論の引き写しではなく、**Memory.md の現在地
（八方塞がり／蓄積の年、UK渡航準備、借金返済、EP制作）に接続して**書く。

- **🐟 魚座** — 今日の星座運
- **🌊 一白水星** — 九星気学
- **🔢 ライフパス5** — 数秘

属性の根拠は `Memory.md`（1999年3月10日生まれ / 魚座 / 一白水星 / 卯年 / ライフパス5）。
**生年月日はノートに書かない。** 属性ラベルだけ使う。

## Step 6: 🌅 今朝のレター を書く

PREV の日記を**本当に読んで**返事を書く。飾らず、詩的に、3〜5文。
PLUR・波動・世界平和の文脈で。批評ではなく、そこにいる人への手紙として。

```
**[PREVの日付]のあなたへ**（[N]日越しの返事 ← 前日なら括弧ごと省略）

**やっておいたよ** — [依頼を実行したときだけ。無ければこの行ごと削除]

**CONNECTIONS** — 前回の日記の出来事・感情と、今起きていることの接続点（1〜2文）

**PATTERN** — 思考・行動に見えるパターン。批評ではなく発見として（1文）

**QUESTION** — 一つだけ。答えより、考え続けてほしい問いを（1文）
```

PREV の日記に「〜しておいて」「調べておいて」といった依頼が書かれていたら、
可能な範囲で実行し（調査=WebSearch/WebFetch、記事化=`wiki/questions/` に保存等）、
成果パスを **やっておいたよ** の行で報告する。
**外部に影響する操作（カレンダー登録・送信・投稿）は実行せず、レターで確認を求める。**

## Step 7: 報告

埋めたセクションと、PREV に選んだ日付をユーザーに伝える。commit はしない
（vault の commit は既存のフックとルーチンに任せる）。
