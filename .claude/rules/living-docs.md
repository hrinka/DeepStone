# LIVING ドキュメント編集ルール

このファイル群は「**常に現在を反映する**」文書であり、履歴を積む場所ではない。

## 原則

- **append しない、蒸留する。** 新しい事実を足すときは、古い記述を消すか圧縮する。
  行数が増え続けているなら、それは使い方を間違えている
- 履歴として残したい記述は `wiki/log.md`（append-only）へ送る。LIVING doc に残さない
- `wiki/hot.md` は「セッション開始時に最初に読むキャッシュ」。**10KB を超えたら失敗**とみなし、
  その場で圧縮する。1 エントリは 1 行 + wikilink まで。詳細は個別ページに置き、ここには置かない
- `updated:` を必ず更新する

## 背景

2026-07 時点で hot.md が 152KB / 129 エントリまで肥大化し、log.md（160KB）とほぼ同内容の
重複になっていた。毎セッション最初に読む前提のファイルがこのサイズだと、キャッシュではなく
ただのコストになる。同じことを繰り返さないためのルール。
