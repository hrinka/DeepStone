# 週次レビュー

過去7日間の `journal/` デイリーノートから予定タスクの完了状況を自動集計するダッシュボード。**Dataview プラグインが必要**（未インストールの場合はクエリブロックがそのままテキスト表示される）。

週1回、ここを見ながら来週の時間割の組み方を調整する。

## 直近7日間の完了率

```dataview
TABLE WITHOUT ID
  file.link AS "日付",
  length(filter(file.tasks, (t) => t.completed)) AS "完了",
  length(file.tasks) AS "全体"
FROM "journal"
WHERE date >= date(today) - dur(7 days) AND date <= date(today)
SORT date DESC
```

## 直近7日間の未完了タスク一覧

```dataview
TASK
FROM "journal"
WHERE date >= date(today) - dur(7 days) AND date <= date(today) AND !completed
GROUP BY file.link
```
