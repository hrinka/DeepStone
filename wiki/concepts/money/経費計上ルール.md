# 経費計上ルール

外注（ミキシング・ビートメイク等、他のクリエイターへの支払い）を中心に、経費として計上する際の判断基準を蓄積していくページ。ケースが増えるたびに追記する。

---

## 勘定科目の目安

- ミキシング・マスタリング・ビートメイク等、他者への制作依頼 → **外注費**
- 機材・ソフトウェア購入 → **消耗品費**（10万円未満）/ 減価償却資産（10万円以上）
- サブスク（DAWプラグイン・クラウド等） → **通信費 or 支払手数料**（性質に応じて）

## ケーススタディ

### 2026-07: ミキシング¥15,000 / ビートメイク¥20,000（別々の個人へ支払い）

- 先方から書面（請求書・領収書）の用意なし
- 対応: 先方に簡易領収書（日付・金額・「◯◯報酬として」・氏名）を発行してもらう + 振込明細を保存 + 自分側で支払いメモを記録
- 源泉徴収: 対象外（[[確定申告方針(青色申告)]] 参照 — 給与支払いのない個人事業主は徴収義務なし）
- 勘定科目: 外注費

→ 今後、同様の外注payment（他のエンジニア・クリエイターへの依頼）はこのフローをデフォルトにする。

## 領収書テンプレ（先方に渡す用）

```
領収書
日付: 20XX年◯月◯日
金額: ¥XX,XXX
但し: ◯◯報酬として
上記正に受領いたしました。
氏名: ◯◯◯◯
```

## 振込完了連絡に添えるメッセージ（実運用テンプレ）

振込完了の連絡と受領確認のお願いは分けず、**1通のメッセージにまとめて送る**。相手が個人クリエイターでカジュアルなやり取りが基本なら以下で十分。

### カジュアル版（LINE等）
```
◯◯さん
ミキシングありがとうございました！
本日¥15,000お振込みしましたので、ご確認お願いします🙏

こちらの経費処理のために、恐れ入りますが受領確認だけお願いできますか？
「¥15,000 ミキシング代として受け取りました」って一言返信いただければ大丈夫です！
```

### フォーマル版
```
◯◯様

お世話になっております。
本日、ミキシング作業の報酬として¥15,000を下記口座へお振込みいたしました。
ご確認のほどよろしくお願いいたします。

お手数をおかけしますが、経費計上のため下記の内容で受領確認（領収書がわりの簡単なご返信で構いません）をいただけますと幸いです。

────
日付: 2026年◯月◯日
金額: ¥15,000
但し: ミキシング作業報酬として
────

よろしくお願いいたします。
```

このメッセージ自体＋相手の返信＋振込明細の3つが揃えば経費として説明できるため、相手が返信をくれなくても最低限の証拠にはなる（返信を強く催促する必要はない）。

## 判断に迷ったときの原則

- 形式より実質。3点セット（領収書 or 受領確認／振込明細／自分のメモ）が揃っていれば経費として説明可能。
- 迷ったら「事業のために使ったと合理的に説明できるか」を基準にする。
- **紙の請求書・領収書は法律上必須ではない。** LINE/メール等のテキストでも「いつ・誰に・いくら・何のために」が分かれば有効な証憑になる（電子帳簿保存法の趣旨とも合致）。避けるべきは「紙かどうか」ではなく「記録が何も残っていない」状態。消費税のインボイス制度は免税事業者には関係ないため、紙の適格請求書がなくても所得税の経費計上に影響はない。

## 補助金申請の証憑は別ルール（確定申告の経費とは区別する）

上記はあくまで**確定申告の経費計上**の話。**補助金（小規模事業者持続化補助金・IT導入補助金・事業再構築補助金等）の対象経費**にする場合は審査基準が全く別で、LINEメッセージ等の簡易な証憑では通らない。

補助金の実績報告で通常必要になる書類一式:
1. 見積書（場合により相見積もり）
2. 発注書・契約書
3. 請求書（先方の氏名・連絡先・金額・内容が明記された正式なもの）
4. 支払証憑（振込明細 or 領収書）
5. 成果物（納品物の証拠）

**重要: 対象にしたい取引は依頼前から正式な見積書・発注書を用意する必要がある。** 後から書類を整えると日付の整合性が崩れ、不正受給を疑われるリスクがある。すでに完了した取引（メッセージのみで済ませたもの）を遡って補助金の対象経費にするのは避ける。補助金を使いたい案件がある場合は、その取引だけ最初から正式なフローで進める。
