# UK渡航 統合ロードマップ

借金完済 → 沖縄ワーケーション（2027-04）→ 大阪DJ → UK WHV渡航 を、
月60万円（税込）の収入を前提に一本の時系列につないだページ。

これまで [[借金返済-キャッシュフロー計画]] と [[2026-07-20-平塚市個人事業主プラン]] で
gap として残っていた「借金完済と200万円貯蓄は同時に達成できるのか」に、
数字で答えるために作成した。

---

## 結論（先に）

| 到達点 | 時期 |
|---|---|
| 借金 ¥1,246,753 完済 | **2027年1月** |
| 貯蓄 100万円 | 2027年6月 |
| 貯蓄 200万円 | **2027年10月** |
| UK WHV 申請 | 2027年5〜6月（渡航6ヶ月前ラインに入る） |
| **UK 渡航** | **2027年11〜12月** |

**リモート継続が確認できれば、これが最大4〜5ヶ月早まる（2027年夏〜秋）。**

## 案件の切り替え方針（2026-08-24 本人確認）

**今後は「海外リモート可能な案件」へ切り替える。**
現在の委託先にリモート継続を打診するのではなく、はじめから海外リモート前提の案件に
移る方が構造的に確実。

- 切り替えは**渡航の1年前まで**に済ませたい（実績と信頼を作る時間が要る）
  → 2027年後半渡航なら、**2026年後半〜2027年前半が切り替え期**。つまり今から動く時期
- 選択肢: 日本企業のフルリモート業務委託（時差許容が条件）／海外エージェンシー経由／
  海外クライアント直
- **契約時に確認すべき点**: 役務提供地が国外になった場合の源泉徴収の扱い
  （[[渡航前後の税務戦略]] の20.42%論点）。ここを契約書で詰められる相手を選ぶ

これが実現すれば、渡英後も収入が途切れないため必要貯蓄は約150万に下がり、
**2027年夏の渡航も射程に入る**。

### 税・社会保険の概算（年間・業務委託前提）

売上 ¥7,200,000 − 経費 ¥900,000 = 事業所得 ¥6,300,000

| 項目 | 年額 | 月割 |
|---|---|---|
| 国民年金 | ¥210,000 | ¥17,500 |
| 国民健康保険（平塚市・単身・40歳未満） | 約 ¥680,000 | ¥57,000 |
| 所得税＋復興特別 | 約 ¥437,000 | ¥36,000 |
| 住民税 | 約 ¥438,000 | ¥36,500 |
| 個人事業税（請負業5%） | 約 ¥170,000 | ¥14,000 |
| **合計** | **約 ¥1,935,000** | **約 ¥161,000** |

### 返済・貯蓄に回せる額

```
収入      ¥600,000
− 経費     ¥75,000   （事業のために実際に出ていく）
− 税・社保 ¥161,000
− 生活費   ¥100,000
─────────────────
= 自由資金 ¥264,000 / 月
```

> [!important] 2027年6月に税金の山が来る
> **住民税と個人事業税は翌年課税。** 2026年分（約¥608,000）の請求は
> 2027年6月以降に届く。上の月¥161,000には月割りで織り込んであるが、
> **キャッシュとしては2027年6月までにこの分をプールしておく必要がある**。
> ここを見落とすと2027年夏に資金ショートする。
> 2026年中の手残りは「多く見える」が、それは翌年の税を先に使っているだけ。

## 投資について — 渡航前は「しない」が正解

借金18%がある間に投資しないのは当然として（18%を確実に得るのと同じ）、
**完済後も渡航前は投資を避けるべき**。理由は利回りではなく制度。

- **NISA は非居住者になると使えない。** 出国時に売却するか、証券会社の継続措置
  （最長5年・対応していない会社もある）に頼ることになる。渡航半年前に始めても
  すぐ畳むことになり、手数料と手間だけが残る
- **iDeCo は非居住者になると掛金拠出が止まる。** しかも60歳まで引き出せない。
  渡航資金として使えない金を積むことになる
- UK には ISA という非課税制度がある。**居住者になってから、そちらで始める方が筋が通る**

→ **渡航までは現金で持つ。** 投資は UK 生活が安定してから。
これは [[個人事業主-立て直しチェックリスト]] の既存方針と同じ結論だが、
理由が「借金優先」だけでなく「非居住者化で制度が使えなくなる」に強化される。

## 渡航時期を最も大きく動かすもの

**渡英後も収入が続く案件を確保できているか。**

| ケース | 必要な貯蓄 | 渡航可能時期 |
|---|---|---|
| 海外リモート案件を確保**できている** | ビザ¥41万 + 航空券¥20万 + 生活費3ヶ月¥90万 ＝ **約150万** | **2027年8月** |
| 確保**できていない** | 上記 + 仕事が見つかるまでの6ヶ月分 ＝ **約200万** | 2027年11月 |

差は約4ヶ月。**貯蓄ペースを上げるより効果が大きい。**
渡英後の収入がゼロにならないので、現地での焦りも消える。

## 出国日の制約 — 2027年12月31日まで

住民税は「1月1日に日本に住所があるか」だけで決まる。年内に転出すれば
2028年度の住民税（2027年所得ベース・**約44万円**）が課税されない。
年明けにずれ込むと消える。詳細は [[渡航前後の税務戦略]]。

→ 渡航時期の下限は資金、**上限は2027年12月31日**。この窓の中で決める。
