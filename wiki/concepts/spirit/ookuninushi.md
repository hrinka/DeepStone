# 大己貴尊 / 大国主（オオクニヌシ）

## 基本プロフィール

| 項目 | 内容 |
|------|------|
| 主要名 | 大国主命（おおくにぬしのみこと） |
| 別名 | 大己貴命（おおなむちのみこと）、八千矛神、大物主神、葦原醜男神など |
| 典拠 | 古事記、日本書紀 |
| 系譜 | 素戔嗚尊の6〜7代目子孫（または直系の子という説） |
| 配偶 | スセリビメ（スサノオの娘）が正妻 |
| 主要神社 | 出雲大社（島根県） |
| 平塚 | [[寄木神社]]（平塚市大神） |

## 多面的な神格

「大己貴」という名は「大いなる土地の主」を意味する。名前によって神格の側面が変わる：

| 名前 | 意味・側面 |
|------|----------|
| **大国主** | 葦原中国（日本）の統治者 |
| **大己貴** | 偉大な土地の精霊・先祖神 |
| **八千矛** | 恋愛・求婚のエネルギー（八千の武器＝愛の矢） |
| **大物主** | 大和の神・三輪山の神（物の主） |

## 神話の軌跡

### スサノオへの試練
スサノオを訪ねた大国主は娘スセリビメに一目惚れ。スサノオはしかし婿入りを認めず、次々と試練を与える：
- 蛇の部屋に泊まらせる
- 蜂・ムカデの部屋に泊まらせる
- 野原に火を放つ

すべてスセリビメの助けで生き延びた大国主は、スサノオが眠った隙に剣・弓・琴を奪い、スセリビメを背負って逃走。スサノオに追われながらも認められる。

> 「その汝の佩ける大刀、汝の持てる弓矢以ちて、汝の庶兄弟をば坂の御尾に追ひ伏せ、また河の瀬に追ひ払ひて、大国主神となりて」

### 国造り
少彦名命（スクナビコナ）とともに葦原中国を造る：
- 農業・稲作の確立
- 医療・薬学（「神代の医学」）
- 縁結び・社会秩序

### 国譲り
天照大神の使者に請われ、「見えない世界の統治」を引き受けることを条件に国を譲る。出雲大社に鎮まる。

## 縁結び信仰の根拠

八千矛神という名が示すように、大国主は数多の恋愛・求婚の物語を持つ神。美しい姫に選ばれ、試練を乗り越え、逃げた先でも認められる——その「縁を引き寄せ、つなぎとめる力」が縁結びの神格の本質。

旧暦10月＝「神無月」。全国の神々が出雲に集まり、翌年の縁結びを決める会議（神議り）を行う。出雲では「神在月」。

## Rinkaのルーツとの繋がり

### 寄木神社（平塚市大神）
Rinkaの地元・平塚市大神に鎮座する[[寄木神社]]は、大己貴命を祭神とする。

由緒：
- **貞観元年（859年）創建**
- 大神朝臣の遠祖・大己貴命を氏神として祀る
- 大神朝臣が相模国大住郡の大領として大神の郷に赴任した際に創建
- 明治6年（1873年）村社に列格

「大神（おおかみ）」という地名そのものが、この神の存在を示している。
