# 瀬織津姫（セオリツヒメ）

## 基本プロフィール

| 項目 | 内容 |
|------|------|
| 別名 | 向津媛命（むかつひめのみこと）、撞賢木厳之御魂天疎向津媛命 |
| 属性 | 水神・祓神・滝神・川神 |
| 典拠 | 延喜式『大祓詞』、ホツマツタヱ |
| 位置づけ | 祓戸四神の筆頭 |

## 謎の正体

古事記・日本書紀に**名前が登場しない**という特異な女神。にもかかわらず、延喜式（927年）の大祓詞には祓戸四神の第一柱として記されており、全国の神社の祝詞に息づいている。

この「公式記録にないのに祀られ続けている」矛盾が「封印された女神」という現代的解釈を生んだ。ただし意図的削除の直接的な史料証拠は現時点では確認されていない。

### ホツマツタヱの記述
日本古史古伝とされる『ホツマツタヱ』では「向津姫」として天照大神の**正妃**として描かれる。天照大神の荒魂＝向津媛命と瀬織津姫を同一視する説はここに根拠を持つ。

## 役割：流す・祓う・解き放つ

> 「山々の頂から滝のように激しく流れ落ちる、早川の瀬にいらっしゃる川の神様で、すべての罪穢れを、川から大海原へと持ち去ってくださる」

祓戸四神の中での役割：

| 神名 | 役割 |
|------|------|
| **瀬織津姫** | 罪穢れを川の瀬から大海へ流す（最初の一押し） |
| 速秋津日子・速秋津比売 | 海で飲み込む |
| 気吹戸主 | 根の国・底の国に吹き放つ |
| 速佐須良比売 | 最終的に消し去る |

瀬織津姫は**浄化プロセスの入口**——溜まったものを動かし、流れに乗せる役割。

## 龍神としての側面

白龍と結びつけて語られることが多い。水を司る神霊が龍の姿で表現される日本の伝統において、**浄化・再生・霊的な導き**を象徴する白龍として捉えられている。

貴船神社の祭神＝瀬織津姫という説も一部研究者の間で語られる（公式見解ではない）。

## 天照大神との関係

伊勢神宮内宮別宮・荒祭宮の祭神の別名が「瀬織津姫」とされる説がある。天照大神の「**荒魂（あらみたま）**」としての側面——荒々しさ・変容・創造性を象徴する。

和魂（にぎみたま）＝穏やかな豊穣の天照 / 荒魂＝激しく浄化する瀬織津姫という対比。
