# フトマニ歌占い——実践ガイド

日本最古の歌占いとされるフトマニ（太占）の現代的実践法。128首の和歌のうち1首を引き、その言霊を今の問いへの答えとして読み解く。

---

## フトマニとは

ホツマツタヱで語られる通り、アマテル神（天照大神・男神説）が八百万の神に命じて詠ませた**128首の和歌**。8種の縦軸音 × 16種の横軸音 = 128の組み合わせ。

モトアケ図（フトマニ図）という宇宙の構造図に配置されており、一首一首が「宇宙のある側面」を言霊として封じている。

---

## 128卦の構造

### 縦軸（8種）
```
ア・イ・フ・ヘ・モ・ヲ・ス・シ
```
（宇宙の8つの根本的な「在り方」）

### 横軸（16種）
```
ヤマ・ハラ・キニ・チリ・ヌウ・ムク・エテ・セネ
コケ・オレ・ヨロ・ソノ・ユン・ツル・ヰサ・ナワ
```
（宇宙の16の「現象・場」）

縦×横のひとつの交点 = ひとつの卦 = ひとつの和歌 = 宇宙のひとつの状態

---

## 実践方法（最もシンプルな方法）

### 方法①：数字で引く

1. **問いを立てる**
   - 心の中で明確な問いを持つ
   - 例：「今日、私がフォーカスすべきことは？」
   - 例：「この選択の方向性は？」

2. **縦軸（1〜8）を決める**
   - 直感、または日付の数字、または瞑想後に浮かんだ数字
   - 1=ア、2=イ、3=フ、4=ヘ、5=モ、6=ヲ、7=ス、8=シ

3. **横軸（1〜16）を決める**
   - 同様に直感または数字で
   - 1=ヤマ、2=ハラ、3=キニ、4=チリ、5=ヌウ、6=ムク、7=エテ、8=セネ
   - 9=コケ、10=オレ、11=ヨロ、12=ソノ、13=ユン、14=ツル、15=ヰサ、16=ナワ

4. **組み合わせを求める**
   - 縦（ア行）× 横（ヤマ列）= 「アヤマ」の卦の歌を読む

5. **歌を読み、言霊を受け取る**
   - 歌の意味を頭でなく感覚で受け取る
   - 言葉が「響く」部分に注目する

---

### 方法②：五十音でランダムに引く

紙に「ア〜ン」を書き、目を閉じて2回指を置く。最初が縦軸の音、次が横軸の音。その組み合わせで卦を求める。

---

### 方法③：日付から引く

```
縦軸 = 今日の日付 ÷ 8 の余り（0なら8）
横軸 = 今日の日付 ÷ 16 の余り（0なら16）

例：6月10日 = 10日
  縦：10 ÷ 8 = 余り2 → イ
  横：10 ÷ 16 = 余り10 → オレ
  → 「イオレ」の卦
```

## フトマニ卦の読み方のコツ

| ポイント | 説明 |
|---------|------|
| **直訳しない** | 歌の言葉を文字通りに解釈しない。「山」なら「高みを目指す」「動かない力」などに読み替える |
| **感情で受け取る** | 歌を読んで何を感じるか。「ほっとする」「不安になる」——その感情が答え |
| **縦軸の音の意味** | ア（始まり）・イ（生命）・フ（膨らむ）・ヘ（変化）・モ（保つ）・ヲ（おわり）・ス（清澄）・シ（根付く） |
| **問いの精度** | 「どうすればいいか」より「今の私の状態は？」など、YESかNOでない問いが良い |

---

## 縦軸8音の意味（基本解釈）

| 番号 | 音 | 意味 | 占いでの読み |
|------|-----|------|------------|
| 1 | **ア** | 始まり・光・顕現 | 新しいスタート・陽のエネルギー |
| 2 | **イ** | 生命・時・息 | 生命力・タイミング・リズム |
| 3 | **フ** | 増える・膨らむ | 成長・拡大・豊かさ |
| 4 | **ヘ** | 変化・へそ（中心） | 転換点・変容・中心を保つ |
| 5 | **モ** | 保つ・育む | 維持・育成・守る |
| 6 | **ヲ** | 終わり・収束 | 完結・手放し・次への準備 |
| 7 | **ス** | 清澄・透明・空 | 浄化・クリア・見通し |
| 8 | **シ** | 静かに根付く | 安定・定着・深化 |

## 実践例

**問い**：「今月のFLAVA FMの発信方向性は？」

**引いた卦**：縦＝フ（3）、横＝ヤマ（1）→「フヤマ」

**フヤマの歌**（例・現代解釈）：
- フ＝膨らむ・増える
- ヤマ＝山・高い所・根拠地
- 読み：「高みに向かって着実に積み上げていく時期。急がず、一歩一歩の積み重ねが力になる。」

**受け取り方**：コンテンツを爆発的に増やすより、質の高い投稿を積み重ねるタイミング。
