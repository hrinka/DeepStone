# ホツマツタヱ（秀真伝）

## 基本情報

| 項目 | 内容 |
|------|------|
| 正式名 | 秀真伝（ほつまつたゑ） |
| 文字 | ヲシテ文字（神代文字の一種） |
| 構成 | 自序 + 40章（アヤ）、五七調長歌体 |
| 分量 | 約11万字。古事記・日本書紀の約2倍 |
| 時代範囲 | 天地開闢〜景行天皇56年（人皇12代） |
| 再発見 | 1966年、松本善之助が古書店で発見 |
| 学術評価 | **偽書**（江戸時代後期の成立と推定）|
| 文化的価値 | 江戸期思想史・国学運動の資料として研究進展中 |

## 成立と発見の経緯

### 江戸時代後期の成立
安永年間（1772〜1781年）の成立と推定されている。根拠は僧侶・溥泉が1780年に著した『春日山紀』に同書と同様の記述が引用されていること。

実際の翻訳者として和仁安聡（井保勇之進）の名が挙がる。歴史記録では「横井川の山伏」かつ「神社由緒の偽作者」と記されている。

### 1966年の再発見
松本善之助が古書店でホツマツタヱの完本を発見。関連文献『太占』『三笠文』の所在も確認し、「これが記紀の原典だ」という信念のもと研究会を設立。1980年に『秘められた日本古代史』を刊行し現代の関心を喚起した。

現在、全国数十か所に研究会が存在し、約400〜数百人が所属（2016年全国フォーラム）。

## 内容と構成

### 三部構成

| 部 | 内容 |
|----|------|
| **天地創造・神代** | イザナギ・イザナミの国生み、カミヨの神々の物語 |
| **天皇系譜** | 欠史八代（2〜9代）の詳細な業績を含む初代〜景行天皇 |
| **文化制度** | 農業・漁業・医療・祭り・暦など古代社会の知識 |

### 前半・後半の編纂者

- **1〜28章**：クシミカタマが編纂
- **29〜40章**：オホタタネコが編纂

（大三輪氏の祖・大田田根子に仮託されている）

## 記紀との最大の相違点

### 1. 天照大神が男神
記紀では女神だが、ホツマツタヱでは「**アマテル神**」として男神として描かれる。富士山をアマテル神の誕生地とする記述もある。

### 2. 瀬織津姫がアマテル神の正妻
記紀に登場しない瀬織津姫（向津姫）が、アマテル神の正室として「内宮」に迎えられたと記述される。これが「瀬織津姫＝天照大神の荒魂」という現代的解釈の根拠の一つ。

### 3. スサノオの表記・出自
「**ソサノヲ**」と記述。ソサ（紀州）で生まれたことに由来。物語の大筋（高天原追放→ヤマタノオロチ退治→クシナダヒメと結婚）は記紀と同じ。

### 4. 欠史八代の詳細
記紀でほとんど記述のない2〜9代天皇について詳細な業績が記されている。

### 5. 五母音 vs 八母音
記紀時代は八母音が使われていたとされるが、ホツマツタヱは現代と同じ五母音を使用。これが偽書論の主要根拠の一つ。

## ヲシテ文字について

幾何学的な形状を持つ神代文字。一音一音が宇宙の5元素と対応しており、それぞれの文字（音）に固有の意味と「言霊」が宿るとされる。

- 母音：宇宙を構成する5元素に対応
- 子音：宇宙の発生過程を意味する
- 各文字が神格を持ち、祭儀・卜占に使用されたという

例：
- **ヤ**：目に見えない宙のエネルギーが熟し次の段階に跳ね上がる「弥栄（いやさか）の力」
- **ヱ**：様々な交わりの中で愛が溢れご縁が広がっていく力

詳細は[[ヲシテ文字]]参照。

## 学術的評価と偽書論争

### 偽書とする主な根拠
1. **江戸時代以前の写本が存在しない**——最古の写本が18世紀以降
2. **五母音の使用**——古代日本語は八母音のはず
3. **江戸時代以降の語彙が含まれる**——当時存在しなかった言葉が複数
4. **先行偽書の影響**——『先代旧事本紀大成経』などの影響が指摘される

### 現在の学術的位置付け
- 「18世紀の偽書」という前提のもとで**近世思想史・文学**の資料として研究
- 原田実・藤原明らが偽書研究を展開
- 吉田唯は「**近世神話**」として解釈（近世に作られた神話として文化的価値を認める）

### 真書論者の立場
- 「記紀の原典がホツマツタヱだ」という主張
- 古事記・日本書紀の謎や矛盾（欠史八代など）をホツマツタヱが解くと主張
