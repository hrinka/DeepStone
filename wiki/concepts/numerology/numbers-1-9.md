各数字のキーワード・色・チャクラ・惑星・タロット・アロマをまとめたリファレンス。

## 3 — 創造と表現のエンターテイナー

| 項目 | 内容 |
|------|------|
| テーマカラー | イエロー |
| チャクラ | 第3チャクラ（みぞおち） |
| 気質/性別 | 陽 / 男性 |

| 対応惑星 | 木星（拡大・発展のエネルギー） |
| タロット | 女帝（豊かさ・創造・喜び） |

**キーワード:** 想像力、楽しい、明るい、子供らしい、無邪気、社交性、ユーモア、自己表現

**形の由来:** 卵がパカッと割れた形。何かが生まれる瞬間のダイナミズム。
**植物イメージ:** 双葉がぐんぐん伸びていく成長期。

**神聖な意味:** 3はあらゆる文化で神聖な数字。
- キリスト教：三位一体（父・子・聖霊）
- 仏教：三宝（仏・法・僧）
- ヒンドゥー教：三神一体（ブラフマー・ヴィシュヌ・シヴァ）
- 日本：三種の神器

### ポジティブな特徴
- いるだけで場が明るくなる
- 純粋・天真爛漫
- コミュニケーション力が高い
- 楽しいことへの本物の情熱

### 注意点
- 「子供の数字」——考えが幼稚になりがち
- 気分の浮き沈みが大きい
- 飽きっぽい・努力が続きにくい

### 対応アロマ

## 4 — 大地に根を張る堅実家

| 項目 | 内容 |
|------|------|
| テーマカラー | グリーン |
| チャクラ | 第4チャクラ（胸・ハートチャクラ） |
| 気質/性別 | 陰 / 女性 |
| 役割 | 縁の下の力持ち |
| 対応惑星 | 地球（コツコツ・実用性） |
| タロット | 皇帝（秩序・責任を持って守る象徴） |

**キーワード:** 安心、安定、現実、誠実、堅実、グラウンディング、四季、東西南北

**形の由来:** プラス記号・四角形・閉ざされた空間。揺るがない基盤。
**植物イメージ:** 大地にしっかり根を張る。どんな風が吹いても倒れない。

**文化的意味:** 日本・中国では「死」と重なる忌み数。欧米では四つ葉のクローバーで幸運の数。四大元素（火・水・土・風）、四季、東西南北——世界の構造そのものを表す数字。

### ポジティブな特徴
- 真面目・コツコツ努力
- 自分軸がしっかりしている
- 結婚・家庭・子育てに向いている（理想のパートナー）
- 組織の中で活躍できる

### 注意点
- 頑固・融通が利かない（「こうあるべき」の守護者）
- 昭和的な価値観になりやすい

### 対応アロマ
| オイル | メッセージ |
|--------|-----------|
| メリッサ（レモンバーム） | 「あなたの目標は叶います」。願望実現オイル |
| ベルガモット | 「信用されるには行動が必要」。アールグレーの原料 |
| クラリセージ | 女性ホルモンを整える・落ち着かせる |
| ウィンターグリーン | 次元上昇オイル（サリチル酸メチル含有・湿布の原料） |
| ゼラニウム | 「女性であることを忘れないで」。感情を守る愛のオイル |

## 9 — 完成と知恵の人道主義者

| 項目 | 内容 |

| 気質/性別 | 陰 / 男性 |
| 役割 | 最終奏者・まとめ役 |

**キーワード:** 完成、知恵、慈悲、平和主義、人道主義、社会貢献

**形の由来:** 知性の詰まった頭を持つ老人の形。長い旅の末の英知。
**植物イメージ:** 収穫後に土を耕す。終わりは次の始まりへの準備。

**数秘的な神秘:** 9の倍数の各桁の和はまた9になる（例: 9×2=18→1+8=9）。全ての数を包む完成された数。

### 特徴
- ボランティア精神・博愛主義
- 優しく気配りができる
- ポーカーフェイスが多い
- 広い視野で物事を見る
- 自分を信頼することが大事
- ポジティブな明るい人と交わると良い

### 注意点
- 同情と慈悲を混同しやすい
- 1人が好きすぎて孤立しがち
