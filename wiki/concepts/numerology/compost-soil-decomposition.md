# 堆肥・土壌分解 — 完全フレームワーク

## 1. 3フェーズ分解サイクル（温度と微生物）

```
[中温相] 10-42°C / 24-72時間
易分解性有機物（糖・タンパク）を消費
→ 熱産生

[高温相] 45-70°C / 数日〜数週間
セルロース・ヘミセルロース・脂質を分解
Bacillus属（87%優占）・高温性真菌・放線菌
→ 病原菌・雑草種子が死滅（55-65°Cが最適）

[成熟相] 50°C以下 / 1-2ヶ月
中温菌が再び優占
→ フミン酸（腐植酸）が蓄積 ← ここが核心
```

**主要微生物ロスター**:
- *Bacillus stearothermophilus*: 65°C超で優占
- *Thermomyces lanuginosus*: 最一般的な高温性真菌
- *Streptomyces* spp.: リグニン等の難分解物を処理する最終分解者

## 2. C:N比（炭素・窒素比）

**原則: 最適比 = 25〜30:1**

| C:N比 | 結果 |
|---|---|
| \>40:1（炭素過多） | 微生物の窒素不足 → 低温・遅い分解 |
| 25〜30:1（最適） | 72時間以内に55-60°C到達・2〜4ヶ月で完成 |
| \<20:1（窒素過多） | 窒素がアンモニアガスとして揮発 → 悪臭 |

**なぜ重要か**:
- 炭素 = 微生物の**エネルギー源**（微生物細胞質量の約50%が炭素）
- 窒素 = タンパク質・核酸・アミノ酸・酵素の構成要素（細胞増殖・機能の基盤）

**素材のC:N比例**:
- 高炭素（茶葉）: 木チップ ~400:1、わら ~80:1、段ボール ~170:1
- バランス: 台所生ゴミ ~15:1、新鮮草刈り ~20:1
- 高窒素（緑葉）: 新鮮糞 ~15:1、コーヒーかす ~20:1

## 3. 腐植酸（Humic Acids）の形成と機能

### 形成プロセス
1. 有機物（植物残渣・動物糞）が微生物により分解
2. 成熟相でリグニン・タンパク複合体が縮合・重合
3. **フミン酸**（高分子・暗褐色・土壌に吸着）と**フルボ酸**（低分子・水溶性・即効性）が生成

### 植物への作用（精油増産メカニズム）
```
フミン酸 → 根細胞膜トランスポーターを改変
→ N・P・K・微量元素の吸収効率化
→ 葉緑素合成促進 → 光合成産物増加
→ テルペン前駆体（IPP・DMAPP）の供給増
→ MEP経路（葉緑体・モノテルペン）活性化
→ 精油腺（グランデュラー・トリコーム）の充填増加
→ 精油含有量・品質の向上
```

### 数値データ（タイム: PMID 29692550）
- フミン酸 0 g/m²（対照）: 精油含有量 **0.8%**
- フミン酸 75 g/m²（最適）: 精油含有量 **2.0%** = **150%増加**
- チモール含有率: 最適区で **74.15%**（カルバクロール 6.20%、p-シメン 4.24%）

## 4. 土づくり哲学（日本的文脈）

**土づくり** = 「作物の食べ物ではなく、**土壌の食べ物**を与える」思想

- 物理性（団粒構造・通気・保水）
- 化学性（pH・養分バランス）
- 生物性（ミミズ・細菌・菌類の活性）

三つを同時に整えることが「土を生命体として育てる」行為

**里山循環との接続**: 都市の有機物廃棄物 → 農地堆肥 → 作物 → 再び都市へ。江戸時代の100万都市がゼロウェイストで機能した原理。
