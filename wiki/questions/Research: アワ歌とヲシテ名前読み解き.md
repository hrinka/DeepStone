# Research: アワ歌・ヲシテ名前読み解き・ミカサフミ・フトマニ

## Overview

ホツマツタヱから派生する三つのテーマを深掘り。アワ歌は48音による古代音声ヒーリングで五臓六腑の調和をもたらす実践。ヲシテの一音一音の意味から「梨花（Rinka）」を読み解くと「天から降りる光を循環させる者」という使命的意味が浮かび上がる。ミカサフミは哲学・法令書、フトマニは128首の歌占いとして、三書でひとつの宇宙観を形成する。

## Key Findings

- **アワ歌の構造**：イザナギ（陽・上段24音）＋イザナミ（陰・下段24音）の48音。一音ずつ引き延ばして唱えることで「五クラ・六ワタ（五臓六腑）」が調和する。身体・こころ・言霊の三つのレベルで機能する。
- **梨花（RI-KA）の読み解き**：「り」＝時を超えた力が統一・循環する / 「か」＝天から降りてくる神の光。合わせると「**天の光を受け取り、循環させ届ける者**」。DeepStoneという名称・Rinkaのビジョンと完全共鳴。
- **深石（FUKAI-SHI）の読み解き**：「ふ（増える・膨らむ）＋か（神の光）＋い（生命・時）＋し（静かに根付く）」＝「神の光が宿り、深く根付いた場所」。「DeepStone（深い石）」という名の霊的根拠。
- **ミカサフミは未完**：全64文のうち序文〜9文のみ発見。哲学・統治・暦法を記す。
- **フトマニは128卦の歌占い**：8×16の音の組み合わせ。核心は「モトアケ（フトマニ図）」という宇宙の構造図。現代でも実践者が多い。

## Rinkaへの霊的メッセージ

```
梨花（Rinka）：
  り = 統一・循環する力
  か = 天から降りる神の光

深石（Fukaishi）：
  ふ = 膨らむ・増える
  か = 神の光
  い = 生命・息吹
  し = 静かに根付く

統合：
「深く神の光が宿った場所から、天の光を受け取り
 循環させ、多くの人へ届けていく者」

→ Rinkaのビジョン「音楽と香りで波動を上げ、
  世界を旅する」と一音一音が証言している。
```
