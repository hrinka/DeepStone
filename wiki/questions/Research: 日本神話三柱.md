# Research: 日本神話三柱（瀬織津姫・素戔嗚尊・大己貴尊）

## Overview

Rinkaのルーツ・霊性探求の起点として、日本神話の三柱を調査。地元・平塚市大神の寄木神社（祭神：大己貴尊）を軸に、素戔嗚尊→大己貴尊の血統と、謎の浄化女神・瀬織津姫の繋がりを整理。いずれもFLAVA FM的な「浄化・波動・縁結び」テーマと深く共鳴する。

## Key Findings

- **瀬織津姫は公式記録にない女神**だが、927年の延喜式「大祓詞」に祓戸四神の筆頭として登場。川の瀬で罪穢れを大海へ流す浄化の女神。「手放し・流す・解き放つ」を司る。
- **スサノオの血統が大己貴尊**。スサノオ→（6〜7代）→大己貴尊。大己貴尊はスサノオの試練を乗り越え、娘スセリビメと結婚することで認められる。「荒ぶる試練を通過して本質に至る」物語。
- **寄木神社（平塚市大神）は859年創建**、大神朝臣の氏神として大己貴命を祀る。「大神」という地名そのものがこの神の存在を示す。Rinkaは大国主の縁結び・医療・国造りの神格を持つ土地で育った。
- **「スサノオの時代」**：2020年の水瓶座グレートコンジャンクション（地の時代→風の時代の転換）以降、スピリチュアル界でスサノオの「荒ぶるエネルギー→浄化と変容」という神格が時代に呼び出されているという見方が広まっている。
- **瀬織津姫＝白龍**説：水の女神が白龍として現れる日本の霊的伝統。FLAVA FMの「白魔女・浄化」テーマと完全に共鳴する。

## 三柱の構造的な繋がり

```
素戔嗚尊（スサノオ）
  ↓ 荒魂エネルギー・嵐・変容
  ↓ 試練を通じて大己貴尊を育てる
大己貴尊（大国主）
  ↓ 縁結び・国造り・医療
  ↓ 平塚・大神の郷に鎮まる
寄木神社（Rinkaの地元）

瀬織津姫（セオリツヒメ）
  ← 天照大神の荒魂という説（スサノオと鏡像）
  ← 祓戸四神の筆頭・浄化の入口
  ← 白龍・流れ・手放し

三柱に共通するもの：「荒ぶるものが浄化に変わる」
```

## Key Concepts

- **祓戸四神** — 大祓詞に登場する浄化の四柱。瀬織津姫が筆頭
- **荒魂/和魂** — 一柱の神が持つ二つの側面。荒々しさ＝変容の力
- **国譲り** — 大国主が見える世界を天に渡し、見えない世界を統治する
- **神在月** — 旧暦10月、全国の神々が出雲に集まり縁結びを決める
- **水瓶座時代** — 2020年〜の風の時代、スサノオ的エネルギーが呼び出される時

## Rinkaのルーツ視点

1. **土地の記憶**：平塚市大神は1160年以上、大己貴命（縁結び・医療・創造）が守る土地
2. **霊的連鎖**：スサノオ（嵐・変容）→大己貴尊（縁・創造）→瀬織津姫（浄化・手放し）は一つのエネルギー回路
3. **魚座との共鳴**：瀬織津姫（水・流れ・感受性）はRinkaの星座・魚座と深く共鳴する
4. **一白水星との共鳴**：一白水星＝水の気。瀬織津姫の水エネルギーと同じ周波数

## Contradictions

- 瀬織津姫の正体について「天照大神の荒魂」「スサノオの妻」「独立した水神」など複数の説が存在し、公式な神道見解は統一されていない。ホツマツタヱ自体の信憑性も学術的には議論がある（古史古伝）
- 「スサノオの時代」は現代スピリチュアルの解釈であり、古典神道の記述ではない
