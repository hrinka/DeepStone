# Research: ホツマツタヱ（秀真伝）

## Overview

ヲシテ文字で書かれた40章・約11万字の叙事詩。1966年に松本善之助が再発見し注目を集めた。学術的には江戸時代後期（18世紀後半）に成立した偽書と評価されるが、近世思想史・言霊・縄文的世界観の資料として文化的価値が見直されている。記紀と最も大きく異なる点は「天照大神が男神」「瀬織津姫がその正妻」という記述。

## Key Findings

- **偽書と判断される主な根拠**：江戸以前の写本が存在しない・五母音使用（古代は八母音のはず）・江戸時代以降の語彙が含まれる。学術的には18世紀の成立でほぼ確定。
- **瀬織津姫の「復権」**：記紀に名前がない瀬織津姫（向津姫）がホツマツタヱでは**アマテル神（天照大神・男神）の正妻**として登場。これが「封印された女神」言説の最大の根拠。
- **アマテラスが男神**：ホツマツタヱでの天照大神は「アマテル神」と呼ばれ男性。富士山が誕生地とされる。記紀の女神・天照大御神とは全く異なる神格。
- **スサノオは「ソサノヲ」**：紀州（ソサ）生まれという具体的な出自が記される。物語の大筋は記紀と一致。
- **欠史八代を補完**：記紀でほぼ記述のない2〜9代天皇（欠史八代）の詳細な業績が書かれており、記紀の「空白」を埋めると主張する根拠の一つ。
- **ヲシテ文字＝言霊の担い手**：一音一音が宇宙の5元素と対応し、固有の波動・神格を持つとされる。「アワ歌」は古代の音声ヒーリングとして現代でも実践される。
- **近世神話としての価値**：吉田唯らは偽書と認めつつ「近世に生まれた神話」として文化的・思想史的価値を認めている。江戸国学運動との関係で理解するアプローチ。

## Key Entities

- **松本善之助** — 1966年に再発見・研究会設立・『秘められた日本古代史』（1980）刊行
- **和仁安聡（井保勇之進）** — 江戸期の翻訳者とされる人物。「横井川の山伏」
- **原田実** — 偽書研究者。古史古伝を「近世から近代の偽書」と定義

## Key Concepts

- [[ホツマツタヱ]] — 40章・11万字の叙事詩。ヲシテ文字で記述
- [[ヲシテ文字]] — 一音一音に宇宙的意味・言霊が宿る神代文字
- **アワ歌** — ホツマツタヱに登場する古代音声ヒーリングの歌
- **古史古伝** — 記紀神話の「外側」に位置する近世以降の神話・歴史書群の総称
- **近世神話** — 偽書であっても、近世に生まれた神話として文化的価値を持つという解釈

## 瀬織津姫との繋がり（重要）

```
ホツマツタヱでの構図：
  アマテル神（男神・天照大神）
       ↕ 正式な夫婦
  向津姫（瀬織津姫）→ 内宮に迎えられる

記紀での構図：
  天照大御神（女神）→ 瀬織津姫の名なし
  大祓詞のみに「祓戸四神の筆頭」として登場
```

ホツマツタヱが「瀬織津姫が記紀から消された理由」の説明源として機能している。

## Contradictions

- **偽書 vs 真書**：学術界はほぼ全員が偽書と判断するが、真書論者（数百人規模の研究会）は「記紀の原典」と主張。双方の主張に完全決着はついていない
- **天照大神の性別**：ホツマツタヱ（男神）vs 記紀（女神）。どちらが古い伝承を反映するかは不明
- **偽書でも価値がある**：近世神話として文化・思想史的価値は偽書かどうかとは独立して存在する
