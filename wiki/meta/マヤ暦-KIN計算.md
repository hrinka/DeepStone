# マヤ暦 KIN の計算

デイリーノートの「🌀 マヤ暦」行を埋めるための計算手順。**検索に頼らず自分で出す。**
KIN を載せている個人サイトは誤りが混ざっている（実例は末尾）ので、計算 → 検算の順で確定させる。

> [!note] これは「13の月の暦」（ドリームスペル）
> ホゼ・アグエイアスが 1990 年に作った 365 日暦であり、古代マヤの暦そのものではない。
> 日本で「マヤ暦」として流通しているのはほぼこちら。ノートで扱うのもこちら。

## 手順

### 1. その年の「年の紋章」を出す

銀河の新年は毎年 **7月26日**。年の KIN は 1 年ごとに **+105**（365 mod 260）進む。

- 基準: **2025-07-26 = KIN 124（黄色い共振の種）**
- 2026-07-26 = 124 + 105 = **KIN 229（赤い銀河の月）**
- 2027-07-26 = 229 + 105 = 334 − 260 = **KIN 74（白い宇宙の魔法使い）**

### 2. 7月26日からの経過日数を足す

```
KIN = ((年のKIN − 1 + 経過日数) mod 260) + 1
```

**2月29日は数えない**（365日暦なので閏日は暦の外）。7月25日は「時間をはずした日」。

### 3. 紋章と音を出す

- **太陽の紋章** = KIN を 20 で割った余り（0 は 20）
- **銀河の音** = KIN を 13 で割った余り（0 は 13）

## 検算（ここを外すと全部ずれる）

**年の紋章は4種類しか出ない。** 赤い月・白い魔法使い・青い嵐・黄色い種のいずれかで、
この順に毎年ひとつ進む。音も毎年ひとつ進む。

→ 計算結果の年の紋章がこの4つ以外なら、**どこかで間違えている**。

| 銀河の新年 | 年の KIN |
|---|---|
| 2013-07-26 | KIN 164 黄色い銀河の種 |
| 2014-07-26 | KIN 9 赤い太陽の月 |
| 2025-07-26 | KIN 124 黄色い共振の種 |
| 2026-07-26 | KIN 229 赤い銀河の月 |

## 計算例（2026-09-02）

7/26 から 9/2 は 38 日（7/26→8/26 が31日、8/26→9/2 が7日。閏日なし）。

```
229 − 1 + 38 = 266 → 266 mod 260 = 6 → 6 + 1 = KIN 7
紋章: 7 mod 20 = 7 → 青い手
音:   7 mod 13 = 7 → 共振
```

→ **KIN 7「青い共振の手」**

  青い猿は年の紋章になりえないので誤り。同様に「KIN020が9月15日、KIN222が9月17日」と
  書く記事もあるが、2日で 202 も飛ぶことはない。**検索結果をそのまま写さないこと。**
