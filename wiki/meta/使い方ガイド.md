# DeepStone 使い方ガイド

> Rinkaの第二の脳。音楽・DJ、コーディング、UK WHV、お金、文化の知識を蓄積するObsidian vault。

---

## Vault フォルダ構成

```
DeepStone/
├── raw/              生素材（記事・PDFなど）— Clawが読むが変更しない
│                     articles / develop / money / music / personal / uk-whv
├── wiki/             Clawが生成・管理する知識ベース
│   ├── hot.md        最近の文脈キャッシュ（毎回更新）
│   ├── index.md      全概念の一行サマリ
│   ├── log.md        操作履歴
│   ├── concepts/     フレームワーク・パターン・考え方

│   ├── questions/    保存した問いと答え
│   ├── projects/     プロジェクト単位のノート
│   └── meta/         このガイドなど vault 自体の情報
├── journal/          日々のデイリーノート
├── rave-team/        Charlotte R1nR1n（レイブ）コンテンツ制作
├── flava-fm/         FLAVA FM（アロマ・数秘・白魔女）コンテンツ制作

├── _templates/       Obsidian テンプレート
```

## 基本ワークフロー

### ① ソースを取り込む（最も基本）

```
1. 記事・PDF・メモなどを raw/ フォルダにドロップ
2. Clawに「ingest [ファイル名]」と言う
3. → wiki/sources/ に要約、wiki/concepts/ に概念ページが自動生成される
```

### ② 会話から保存する

```
1. Clawと話して有益な内容が出たら
2. 「/save」または「これ保存して」と言う
3. → wiki/questions/ や wiki/concepts/ に整理して保存される
```

### ③ 自律リサーチ

```
1. 「/autoresearch [調べたいトピック]」と言うだけ
2. → Clawがウェブ調査してwikiに書き込んでくれる
```

### ④ 質問・検索

```
「〜について教えて」と言うとClawがwikiを参照して答えてくれる
```

### ⑤ wiki健全性チェック

```
「/wiki-lint」と言うと、リンク切れ・空ページ・孤立ノートを報告してくれる
```

## よく使うコマンド一覧

| コマンド | 何をする？ |
|---|---|
| `ingest [ファイル名]` | raw/ のソースをwikiに取り込む |
| `/save` | 今の会話をwikiに保存 |
| `/autoresearch [トピック]` | 自律ウェブリサーチ → wiki保存 |
| `/wiki` | vault状態確認・足りないページの補完 |
| `/wiki-query [質問]` | wikiを横断して調査・回答 |
| `/wiki-lint` | wiki健全性チェック（リンク切れ等） |
| `/canvas [指示]` | Obsidianキャンバスにビジュアルマップを作成 |

## コツ

- **まず raw/ に放り込む**：整理は後でいい。Clawがingestしてくれる。
- **会話しながらためる**：「これ保存して」が習慣になると知識が積み上がる。
- **hot.md を見ればざっくりわかる**：最近の文脈はここに凝縮されている。
- **完璧を目指さない**：「あとで検索できる」を最優先にする。
- **wikilinks を活用する**：`[[概念名]]` でノート間をつなぐとグラフビューが育つ。

## Clawとのセッションの流れ

```
セッション開始 → Clawが hot.md → index.md の順に読んで文脈を把握
作業中       → 必要なページを随時読み込む
セッション終了 → /save や「hot.md 更新して」で文脈を次回に引き継ぐ
```
