# DeepStone 使い方ガイド

> Rinkaの第二の脳。音楽・DJ、コーディング、UK WHV、お金、文化、雑多な知識を蓄積するvault。

## どんなメモを入れる？

| 種類 | 具体例 |
|---|---|
| **生素材（ソース）** | 読んだ記事・PDF・YouTube要約・Twitterスレッド |
| **学んだ知識** | DJ機材の使い方、音楽理論、コードパターン |
| **UK WHV関連** | ビザ情報、渡航準備、現地の生活情報 |
| **お金・副収入** | アイデア、実績、気づき |
| **疑問・問い** | 後で調べたいこと、未解決の問い |

## 基本ワークフロー

### ① ソースを取り込む（最も基本）

```
1. ファイル（PDF、txtなど）を raw/ フォルダにドロップ
2. Clawに「ingest [ファイル名]」と言う
3. → wiki/ に自動で整理・要約される
```

### ② 会話から保存する

```
1. Clawと話して有益な内容が出たら
2. 「/save」または「これ保存して」と言う
3. → wiki/questions/ や wiki/concepts/ に入る
```

### ③ 自律リサーチ

```
1. 「/autoresearch [調べたいトピック]」と言うだけ
2. → Clawがウェブ調査してwikiに書き込んでくれる
```

### ④ 質問・検索

```
「〜について教えて」と言うとClawがwikiを参照して答えてくれる
（/wiki-query を内部で使う）
```

## Vault フォルダ構成

```
raw/              生素材（記事・PDF・メモ）
wiki/
  hot.md          最近の文脈キャッシュ（Clawが自動更新）
  index.md        全ページの一行サマリ
  log.md          操作履歴
  concepts/       フレームワーク・パターン・考え方
  entities/       人物・ツール・組織
  sources/        取り込んだソースの要約
  questions/      保存した問いと答え
  comparisons/    比較分析
  canvases/       ビジュアルマップ
  meta/           このガイドなどvault自体の情報
_templates/       Obsidianテンプレート
_attachments/     画像・PDF添付ファイル
```

## よく使うコマンド一覧

| コマンド | 何をする？ |
|---|---|
| `ingest [ファイル名]` | rawフォルダのソースをwikiに取り込む |
| `/save` | 今の会話をwikiに保存 |
| `/autoresearch [トピック]` | 自律ウェブリサーチ → wiki保存 |
| `/wiki` | vault状態確認・足りないページの補完 |
| `/wiki-query [質問]` | wikiを横断して調査 |
| `/wiki-lint` | wiki健全性チェック（リンク切れ等） |

---

## コツ

- **まずraw/に放り込む**：整理は後でいい。Clawがingestしてくれる。
- **会話しながらためる**：「これ保存して」が習慣になると知識が積み上がる。
- **hot.mdを見ればざっくりわかる**：最近の文脈はここに凝縮されている。
- **完璧を目指さない**：Zettelkastenより「あとで検索できる」を優先。
