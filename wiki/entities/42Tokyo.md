# 42Tokyo

フランス発・世界42拠点の選抜制エンジニア養成機関。Rinka が2022〜2025年の3年間で修了。

## 概要

| 項目 | 内容 |
|---|---|
| 本部 | フランス・パリ（42 Network） |
| 拠点数 | 世界42拠点 |
| 学費 | 無料 |
| 合格率 | 約10% |
| 学習形式 | ピアラーニング（講師・教科書なし、仲間同士で教え合う） |
| Rinka 在籍 | 2022〜2025年（修了） |

## カリキュラム

低レイヤから上位レイヤまで一貫:
- **C言語**: メモリ管理・プロセス・ポインタ
- **ネットワーク**: ソケット通信・プロトコル実装
- **C++**: IRCサーバー・マルチクライアント接続
- **Web**: Django・Ruby on Rails
- **セキュリティ**: 実践的なセキュリティ知識
- **最終課題**: docker-compose + WebSocket + Three.js のリアルタイム3Dピンポンゲーム（4名チームリード）

## 42Tokyo が培ったもの

**ドキュメントを読んで自走する力**: 講師・教科書なしの環境で、一次情報から答えを見つける習慣。

**ピアラーニング**: わからなければ仲間に聞く。コミュニケーション力と教える力が同時に鍛えられる。

**低レイヤ理解**: C / C++ レベルの実装経験が、上位レイヤの設計判断に活きている。

## Rinka の評価

「42Tokyoでの経験がベースにあって、『何をすればいいか』が与えられない環境で、自分でゴールを設定して毎日前進し続ける習慣が身についた。スタートアップ的なスピード感の環境でこそ力を発揮できる。」
