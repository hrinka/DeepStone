# Metalheadz — Blue Note Sunday Sessions と Drum and Bass の知性化

## 概要

Metalheadz は1994年にゴールディー（Clifford Joseph Price）、ケミストリー（Kemistry）、ストーム（Storm）によって設立されたドラムンベースの伝説的レーベル。1995年から1999年にかけてロンドン・Hoxton の Blue Note クラブで開催された週次クラブナイト「Sunday Sessions」は、ドラムンベースを「ジャングル」から「知的な音楽形式」へと昇華させた場として、ジャンル史上最重要のクラブナイトのひとつに数えられる。

## 背景・歴史

### Goldie の生い立ち — 施設・グラフィティ・金歯

ゴールディーはイングランド・ウォルソール生まれ、ウォルバーハンプトン育ち。3歳で施設に預けられ、複数の里親家庭を転々とした。最初に「言語」として見つけたのはグラフィティアート。その才能が評価され渡米、ニューヨークとマイアミでグリル（金歯ジュエリー）のビジネスを展開。1988年にロンドンに戻り、音楽と出会う。

1992年、Rage というクラブでファビオ＆グルーヴライダーのハードコア/初期ジャングルセットを聴いたことで転換点を迎えた。ケミストリーとストームがゴールディーをその夜に連れて行き、帰り道に彼は「これを作りたい。俺たちでレーベルを作ろう」と言った——Metalheadz の構想はその会話から始まった。

### Rufige Kru と「Terminator」（1992年）

音楽活動を始めたゴールディーは Rufige Kru（後に Metalheads）名義でリリースを開始。1992年のシングル「Terminator」は、タイムストレッチ技術を初めてジャングルに応用した実験的な作品として評価される。音楽評論家サイモン・レイノルズは「ゴールディーはジャングルを一度ではなく三度革命した」と記している：「Terminator」でタイムストレッチを導入し、「Angel」でライブボーカルとオーケストラサンプルを融合し、「Timeless」で22分のハードコア・シンフォニーを作った。

### Metalheadz 設立（1994年）

1994年、ゴールディー、ケミストリー、ストームの3人が Metalheadz レーベルを設立。初のリリースはドック・スコット（Doc Scott）の「V.I.P. Drumz」とゴールディーの「V.I.P. Riders Ghost」のスプリット12インチ。リリースに添えられたプレスリリースには「ブレイクビートとジャングルの根を探求し、新次元のドラムンベースへと再構成する」と記された。

### Blue Note Sunday Sessions（1995〜1999）

1995年7月、Metalheadz は Hoxton の Blue Note クラブで毎週日曜夜の定期クラブナイトを開始。当時の Hoxton は「本当に荒廃したロンドンの一角」（ストーム談）だった。

**Blue Note の物理的特性がサウンドを決定づけた**:
- 天井が極めて低く、ベースが逃げずに密度を保った
- 「完全に音に包まれる感覚だった」（ストーム）
- 照明は暗く、圧迫的だった

この物理的な「囲い込み」が、ドラムンベースの「体験」としての純度を高めた。Rage や Speed と並んで「ジャンルの歴史で最も頻繁に引用されるクラブナイト」として位置づけられる。

**日曜開催の戦略的意味**: 日曜という普通は「脱力の日」を選んだことで、週末パーティ客ではなく音楽に真剣なプロデューサーやリスナーが集まった。ストームは「日曜は、レイブが怖い人たちを引き出す日でもあった」と語る。

**Sunday Sessions に登場した主な名前**:
- Photek（Rupert Parkes）— ジャズとドラムプログラミングの融合
- Dillinja — ダーク＆テクニカルな重低音
- Grooverider — Rage から続くジャングルの伝道師
- Doc Scott — レーベル最初のリリース
- Source Direct — アトモスフェリックかつダーク
- Alex Reece — 「Pulp Fiction」でジャズ・DnBを定義
- Peshay — ジャズとドラムンベースの接点
- Ed Rush & Optical — 暗く無機質なテクノイズム
- J Majik — アトモスフェリック系

### 「Timeless」アルバム（1995年8月7日）

ゴールディーのデビューアルバム「Timeless」は1995年8月7日、FFRR Records よりリリース。冒頭トラック「Inner City Life」が22分に及ぶブレイクビート・シンフォニーとして構成され、ダイアン・シャールマーニュ（Diane Charlemagne）のボーカルがオーケストラ音源と絡み合う。UKアルバムチャート7位。

> 「ドラムンベースは初めて『音楽』と呼ばれた」

それまでダンスフロア消費材だったジャングルが、アルバムという批評的文脈に置かれた最初の例。Mixmag、NME、Wire 誌が高評価。

### Kemistry の死と Sunday Sessions の終幕（1999年）

1999年4月25日、創設メンバーのケミストリー（Kemistry）が交通事故で死亡。享年31歳。彼女の死は Metalheadz の第一章の終わりを象徴し、Blue Note Sunday Sessions も同年に幕を閉じた。

### その後

Metalheadz はその後も活動を継続。現在も年1〜2回の Blue Note リユニオンイベントを開催。2019〜2020年には25周年を記念した一連のイベントとリリースが行われた。

## KEY POINTS

- Metalheadz（1994）は施設育ちのグラフィティアーティスト Goldie と DJ デュオ Kemistry & Storm によって設立された
- Blue Note Sunday Sessions（1995〜1999）は「天井の低さ」という物理的条件が作り出したドラムンベース史上最重要のクラブナイト
- Goldie「Timeless」（1995年8月）はドラムンベースを批評的・芸術的文脈に置いた最初のアルバム作品
- 日曜開催という選択が「音楽家のための夜」という空気を生んだ
- 1999年のケミストリーの死は Sunday Sessions の終わりと Metalheadz 第一章の閉幕を象徴した
- 創設当初から「ジャングルの根を探求し新次元へ再構成する」というコンセプトが明確に宣言されていた
