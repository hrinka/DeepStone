# 技術知識メモ

## 概要

Rinka の技術調査メモ（短い断片）。Terraform・SRE・IaC を調べる入口として作成。詳細は [[AWS Infrastructure]] コンセプトページを参照。

## メモ内容

- **Terraform とは？** → [[AWS Infrastructure]] 参照
- **SRE とは？** → Site Reliability Engineering。Googleが提唱。インフラ運用をソフトウェアエンジニアリングで解決するアプローチ。
- **IaC** → Infrastructure as Code。インフラ定義をコードで管理し、バージョン管理・自動化・再現性を実現。Terraform が主要ツール。
