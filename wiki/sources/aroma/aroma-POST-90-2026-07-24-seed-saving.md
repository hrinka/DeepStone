# 種採り（シードセービング）— 花が終わるとき、植物は来季に手紙を書いた

## 概要

種採り（採種）とは、育てた植物から種子を採取し、翌年の栽培に使う伝統的な農・園芸の実践。固定種（在来種）であれば、採取した種から親植物と同じ形質の植物が育つ。ハーブ菜園において種採りは「植物との長期的な約束」であり、生命の継承という深い波動的意味を持つ。

## 背景・知識

### 種形成の科学

受粉（pollination）→ 受精（fertilization）→ 種子形成 → 成熟 → 散布という段階で種は生まれる。花びらは受粉後に役目を終え、植物は全エネルギーを種子の形成に集中させる。一粒の種の中には「胚（embryo）・胚乳（endosperm）・種皮（testa）」という三層構造があり、植物の生命情報と次世代への栄養が詰まっている。

種子休眠（seed dormancy）により、種は適切な季節まで発芽しない。光受容体フィトクロムが季節の光を読み、適切な春が来るまで眠り続ける。

### Rinka の庭での採種実践

**採種できるハーブ:**
- **セージ**: 花後（7〜9月）に黒い種子が成熟。花穂が茶色くなったら収穫。
- **タイム**: 花後に微細な茶色の種。花穂ごと切って乾燥させ、紙の上でこすって種を取り出す。
- **メリッサ（レモンバーム）**: 非常に旺盛。こぼれ種で自然繁殖するほど。最も採種しやすい。
- **パセリ**: 二年草。1年目は葉のみ、2年目（夏）に白い傘型の花が咲き種がつく。

**採種が難しいハーブ:**
- **ペパーミント（最重要）**: スペアミント（*Mentha spicata*）× ウォーターミント（*M. aquatica*）の自然交雑種。染色体の数の差により**不稔（sterile）**—— 種をほとんど作れない。繁殖は地下茎（ランナー）のみ。→ 「種なしでも地上で最も広がるハーブ」という逆説。
- **ラベンダー**: 市販品種の多くが交雑。採種しても品種が安定せず、挿し木が主流。
- **ジャスミン**: 日本の気候では結実しにくい。

### 固定種 vs. F1品種

| | 固定種（在来種・heirloom） | F1品種（一代雑種） |
|--|--|--|
| 採種 | できる（翌年同じ植物が育つ） | できない（形質が分離する） |
| 歴史 | 何世代も続く命のリレー | 毎シーズン種を購入 |
| 多様性 | 高い（地域の記憶を持つ） | 均一化（効率優先） |
| 精神性 | 継承・魂の連続 | — |

**日本の固定種文化**: 江戸時代から農家は種を家宝として守ってきた。近年、「野口のたね」など固定種専門の種苗家が、失われた在来種の保護・復活に取り組んでいる。

## 波動との繋がり

1. **意図の植え付け**: 種を封筒に入れる瞬間は、来年の植物への「意図の手紙」を書く行為。その意図が種という物理的なキャリアに刻まれる。

2. **時間を越える記憶**: 種の中には何百世代もの植物の「経験と適応」が遺伝情報として記録されている。それは生物学的データでありながら、波動的な意味では「祖先の知恵の結晶」でもある。

3. **ペパーミントの逆説**: 種を持たないにもかかわらず、地下茎で無限に広がるペパーミント。「型がないから、形にとらわれない」。別の道を知っている生命の知恵。

4. **散ることで続く**: 花の美しさが終わるエネルギーが種に変換される。「終わり」は「始まり」に形を変えただけ。無常（むじょう）と継続が同時に存在する。

5. **固定種 = 魂の継承**: 固定種の種を受け取ることは、その植物が生きてきた時間と場所を受け取ること。採種は「波動の継承儀式」。

## KEY POINTS

- 受粉後、植物は花びらを手放して種形成に全エネルギーを注ぐ（散るのは消えるためではない）
- ペパーミントは交雑種のため不稔——種なしで地上最強の繁殖力を持つ逆説
- 固定種は採種できる。F1品種は翌年同じ植物にならない
- Rinka の庭で採種しやすいのはセージ・タイム・メリッサ・パセリ
- 採種のタイミング: 花穂が茶色くなり、軽く触れると種がこぼれ落ちる頃
- 保存: 乾燥後に紙封筒へ入れ、植物名・日付を記して冷暗所（5〜10°C）で
- 種を封筒に入れる瞬間を「来年の自分への意図の手紙」として扱う白魔女儀式
