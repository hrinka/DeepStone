# 腐植酸・有機堆肥とアロマハーブ精油品質の科学

## 核心メカニズム: 腐植酸がなぜ精油を増やすか

### 根への作用（2段階）
1. **低分子フミン酸**: 根細胞内に直接入り込み、細胞内シグナルを誘発
2. **高分子フミン酸**: 根の外側受容体に結合 → 分子応答を引き起こす

### 生化学的カスケード
- 芳香族環を持つフミン酸が細胞膜と相互作用 → 膜トランスポーターを改変
- ROS（活性酸素種）シグナリング経路を活性化 → ホルモン（ジャスモン酸・オーキシン）遺伝子発現誘導
- キレート作用でN・P・K・微量元素の生物学的利用能を向上
- 葉緑素形成を促進 → 光合成産物（糖）増加 → テルペン合成の基質供給増

### テルペン合成経路との接続
- 主経路1: MEP経路（メチルエリスリトール4リン酸経路）——葉緑体内・モノテルペン合成
- 主経路2: MVA経路（メバロン酸経路）——細胞質内・セスキテルペン合成
- フミン酸による栄養強化 → 両経路への前駆体供給が増加 → 精油含有量・組成に直接影響

## 主要研究データ

### タイム (Thymus vulgaris L.)
**研究**: PubMed PMID 29692550 / 温室実験
- フミン酸施用量: 0 / 50 / 75 / 100 g/m²
- 精油含有量の変化:
  - コントロール（0g）: **0.8%**
  - 最適（75g/m²）: **2.0%**（= 150%増加）
- 最適施用時の主成分: チモール74.15%、カルバクロール6.20%、p-シメン4.24%、ボルネオール3.42%
- 分析手法: GC-MS + GC-FID、水蒸気蒸留で精油抽出
- 同定揮発成分: 計32化合物（施用量で組成も変化）

### バジル (Ocimum basilicum)
**研究**: Springer CBTA (2021) / Verrillo, Cozzolino, Spaccini ら
- ソース: アーティチョーク残渣由来の緑コンポストから抽出したフミン酸
- 分析: ¹³C-CPMAS NMR + 熱分解GC/MS で分子構造解明
- 結果: フミン酸バイオスティミュラント処理でバジルEOの**抗酸化活性向上 + 抗菌活性増加**
- 具体的: Klebsiella pneumoniae 等のグラム陰性細菌への抗菌性が有意強化
- DOI: 10.1186/s40538-021-00226-7

### ラベンダー (Lavandula angustifolia)
**研究**: PMC12693513 / Molecules 2025
- 樹皮＋下水汚泥コンポストの混合培地
- 結果: 最多花穂数・最高乾燥重量を達成（有機コンポスト区が最優秀）
- DOI: 10.3390/molecules30234545

**追加**: Lavandula latifolia
- PMC11700101: マルバ抽出物 + フミン酸バイオスティミュラント 野外実験
- EO組成・成長パラメータ双方に有意影響

### ローズマリー (Salvia rosmarinus / Rosmarinus officinalis)
**研究複数**:
- Azollaコンポスト + PGPR + バイオチャー組み合わせで精油含有量・乾燥重量・栄養吸収が有意増加
- 主成分（コンポスト処理有）: カンファー・1,8-シネオール・α-ピネン・カンフェン・α-テルピネオール・ボルネオール
- Academia.edu: コンポスト + 微生物製剤でフォリア（葉面）テルペノイドプロファイル改変

### コリアンダー (Coriandrum sativum)
**研究**: Scientific Reports (2022) / DOI: 10.1038/s41598-022-11555-4
- フミン酸 + 肥料タイプの複合実験
- フミン酸がEO含有量・栄養吸収・成長応答すべてに有意影響

## 土壌有機物と精油の定性的法則

1. **有機炭素(SOC)が高い土 → 微生物活性が高い → 菌根菌(AMF)共生促進 → 精油増加**（POST-81と接続）
2. **フルボ酸 vs フミン酸**: フルボ酸は低分子・水溶性で即効性。フミン酸は高分子・長期的土壌構造改善
3. **リン酸の生物学的利用能**: フミン酸はPをキレート化し根が利用しやすい形に変換——この燐は二次代謝産物（テルペン合成）の直接前駆体輸送に関わる
4. **土壌pH**: 地中海ハーブに最適なpH 6.5〜7.5 は、フミン酸の溶解性・活性が最も高い範囲と一致
