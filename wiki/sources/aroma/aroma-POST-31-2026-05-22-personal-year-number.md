# 個人年（パーソナルイヤーナンバー）— 9年サイクルと2026年の波動

## 概要

数秘術における「個人年（Personal Year Number）」は、誕生月・誕生日・今年の西暦から算出される1〜9の数字。人生を9年周期のサイクルとして捉え、「今年自分がどの波の中にいるか」を示す指針となる。2026年はユニバーサルイヤー1（2+0+2+6=10→1）であり、地球全体が新しい始まりのエネルギーを持つ年にあたる。

## 計算方法

```
個人年 = 誕生月 + 誕生日（各桁の和）+ 今年の西暦（各桁の和）
　　　　→ 1桁になるまで足し続ける
　　　　（11・22 はマスターナンバーとして残す流派あり）
```

**例: 3月10日生まれの2026年個人年**
3 + 1 + 0 + 2 + 0 + 2 + 6 = 14 → 1 + 4 = **5**（自由・変化・旅）

## 9年サイクルの全体像

数秘術では、人生は9年ごとにひとつの螺旋サイクルを描くと考えられている。各年には固有のエネルギーと課題があり、そのリズムを知ることで流れに抵抗なく乗れるようになる。

| 個人年 | キーワード | 波動テーマ |
|--------|-----------|------------|
| 1 | 新しい始まり・種まき | 9年の扉を開く。何を始めるかが次の9年を決める |
| 2 | 育てる・待つ・関係性 | 根が張る年。焦らず、流れに身を委ねる |
| 3 | 表現・喜び・創造性 | 内なる声を外に出す。笑いと創造が開花する |
| 4 | 基盤・努力・規律 | 地に足をつける。コツコツが力になる |
| 5 | 自由・変化・旅 | 流れが大きく変わる。移動・出会い・新環境 |
| 6 | 愛・責任・コミュニティ | 人との繋がりを深める。与えることで豊かになる |
| 7 | 内省・精神性・孤独 | 静かに深く潜る。魂の声に耳を澄ませる |
| 8 | 豊かさ・達成・収穫 | 蒔いた種が実を結ぶ。受け取ることが重要 |
| 9 | 手放し・完成・感謝 | サイクルの完結。手放すことで次の扉が開く |

## 2026年 ユニバーサルイヤー 1

2026年は世界全体が「個人年1」のエネルギーを共有する年。新しい革新・リーダーシップ・原点回帰のテーマが地球規模で動く。個人の個人年が何であれ、2026年に始めたことには宇宙的な後押しがある。

## 波動との繋がり

数秘術の「個人年」は、宇宙のリズム（周波数）に人生を同期させるツールである。各数字には固有の振動数とエネルギーパターンがあり、自分がどの波に乗っているかを「知る」こと自体が波動を上げる行為。

- 個人年に逆らう（変化の年に執着する、手放しの年に積み上げようとする）と消耗する
- 流れを知ることで、アクションとエネルギーを最も効果的なタイミングで使える
- 宇宙のリズム × 個人の意図 = 最大の共鳴（レゾナンス）

## KEY POINTS

- 個人年は「誕生月 + 誕生日 + 今年の西暦の各桁の和」で計算
- 人生は9年周期のサイクルを螺旋状に繰り返す
- 2026年はユニバーサルイヤー1：地球全体が新しい始まりの年
- 自分の個人年を知ることで、宇宙のリズムと同期できる
