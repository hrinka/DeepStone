# ローズオットー（ダマスクローズ）— 愛の周波数

## 概要

ダマスクローズ（Rosa damascena）から水蒸気蒸留で得るローズオットーは、1kgの精油に350〜500万輪の薔薇が必要な世界最高価格クラスの精油。5000年以上の歴史を持ち、臨床試験でうつ・不安・ストレスの有意な低下が確認されている。600種以上の芳香成分が複合して「薔薇の香り」を形成する唯一無二の精油。

## 背景・知識

### 生産

- 主産地: ブルガリア「バラの谷」（Kazanlak）、トルコ → 世界生産の約80%
- 収穫期: 毎年5月〜6月上旬の20日間のみ
- 収穫方法: 夜明け前3〜6時に手作業（日が昇ると香り成分が揮発する）
- 生産量: 1kgの精油に花3.5〜5トン（350〜500万輪）

### 歴史

- 5000年以上前: ペルシャ・インドで使用
- 11世紀: アヴィセンナ（イブン・スィーナ）が水蒸気蒸留法を確立し薔薇水を普及
- 13世紀: 十字軍がダマスカスから欧州に持ち帰る → 「ダマスクローズ」の名の由来
- 現代: Chanel、Dior等の高級香水のベース素材

### 主要芳香成分

| 成分 | 含有率 | 主な作用 |
|------|--------|----------|
| シトロネロール | 30〜40% | 鎮静・抗炎症 |
| ゲラニオール | 10〜25% | 抗菌・高揚 |
| ネロール | 5〜10% | 鎮静・皮膚再生 |
| リナロール | 1〜3% | GABA活性・不安軽減 |
| その他 | 微量 | 600種以上の複合成分 |

## 科学的根拠

1. **臨床試験（血液透析患者）**: ダマスクローズ芳香吸入 → 不安・うつ・ストレス指数が有意低下（HADS・PSS指標）
2. **術前不安軽減（ScienceDirect, 2019）**: 手術前患者へのローズオイル吸入 → 不安スコア有意低下
3. **神経化学的作用**: ドーパミン放出促進 → 抑うつ症状改善。血圧・心拍数・コルチゾール低下。
4. **逆説**: 「落ち着くのに気分が上がる」— メリッサ（POST-53）・ベルガモット（POST-50）と共通する「沈静×高揚」パラドックス

## 波動との繋がり

ローズオットーはハートチャクラ（第4チャクラ）に対応する精油とされる。愛・感受性・繋がりをつかさどるチャクラを直接活性化する。

ギリシャ神話でアフロディーテ（愛の女神）が自らのシンボルに選んだ花であり、5000年にわたって「愛の象徴」として文化圏を超えて共鳴し続けてきた。

600種以上の成分が統合されて初めて「薔薇の香り」になるという事実は、複雑で多面的な感情（痛み・喜び・愛・悲しみ）がすべて統合されたとき、初めて本当の自分になるという白魔女的視点と完全に重なる。

350万輪が1kgに凝縮されるプロセスは、人生の経験・痛みが愛に変わる錬金術のメタファー。

## KEY POINTS

- 1kgに350〜500万輪 → 世界最高価格クラスの精油
- 収穫期はわずか20日間・夜明け前に手で摘む
- 臨床試験でうつ・不安・ストレスの有意低下を確認
- 600種以上の成分の複合 → 合成で再現不可
- ハートチャクラ対応・「愛の周波数」の精油
- 「落ち着くのに気分が上がる」逆説（沈静×高揚）
