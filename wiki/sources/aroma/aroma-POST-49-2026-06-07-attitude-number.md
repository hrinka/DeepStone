# アティテュードナンバー — 外側に発する波動と第一印象の数秘学

## 概要

アティテュードナンバー（別名: サンナンバー / Sun Number）は、生まれた月と生まれた日を足して1桁に還元することで求める数秘術のナンバー。ライフパス数が魂の内側の目的を示すのに対して、アティテュードナンバーは「他者が最初に受け取る波動」「意識する前に届く周波数」を表す。

## 計算方法

**生誕月 + 生誕日 = アティテュードナンバー**（1桁に還元。マスターナンバー11・22は還元しない）

例: 3月10日 → 3 + 1 + 0 = **4**

生まれた年は使用しない。

## 背景・知識

### ライフパス数との違い

| 項目 | ライフパス数 | アティテュードナンバー |
|---|---|---|
| 計算に使う情報 | 生年月日すべて | 月+日のみ |
| 意味するもの | 魂の目的・内側の本質・人生の旅の性質 | 外側の波動・第一印象・社会に向けて発する周波数 |
| 現れるタイミング | 深い関係・時間をかけた理解のとき | 出会った瞬間・最初の接触 |

### 各数字の意味

- **1**: 独立・強い個性・自立した雰囲気。時に「取っつきにくい」と感じられるが、それは根の深い木のような安定感から来る
- **2**: 共感・協調・直感。場の波動を黙って整える受容的な力
- **3**: 表現・社交・ユーモア。言葉と笑いで場を変容させる創造力
- **4**: 信頼・安定・誠実。大地のような安定感。「ちゃんとしている」を体現する
- **5**: 大胆・自由・変化への適応力。風のような流動性とエネルギー
- **6**: 調和・美・ケア。気づかぬうちに周囲を整える愛の磁場
- **7**: 神秘・知性・内向性。謎めいた雰囲気の中に深い観察眼
- **8**: 実用的な権威感・強い意志・頼りになるリーダー性
- **9**: 慈悲・共感・霊的な知恵。最後の数字が持つ「始まりの愛」

## 波動との繋がり

アティテュードナンバーは「言葉より先に波動が届く」という真実を数字で表したもの。私たちは初対面の人に対して、言葉も表情も意識する前に、その人の「周波数」を感じ取っている。それがいわゆる「なんとなく合う・合わない」「一緒にいると落ち着く・疲れる」という感覚の源泉の一つ。

アティテュードナンバーが「偽物の仮面」ではなく「もう一つの本物」である点が重要。ライフパス数が内側から育つ魂の目的なら、アティテュードナンバーは魂が外側に纏う霧のような外套。どちらも魂の段階で選択してきた、多層的な自己の表現。

## KEY POINTS
- 計算方法: 生誕月 + 生誕日（年は不要）
- ライフパス数（内側・魂）とアティテュードナンバー（外側・波動）はセットで理解する
- 両者が「矛盾」に見えても、それは多層的な自己の豊かさ
- 例: ライフパス5（自由・冒険）+ アティテュード4（安定・信頼） = 「外から見ると落ち着いているが内側は冒険者」
