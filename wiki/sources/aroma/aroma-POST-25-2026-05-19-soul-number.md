# ソウルナンバー — 名前の母音が宿す魂の欲求

## 概要

ソウルナンバー（Heart's Desire Number / Soul Urge Number）とは、ピタゴラス数秘術体系において、フルネームの母音から算出する数字。ライフパス数（生年月日）が「人生のテーマ・使命」を示すのに対し、ソウルナンバーは「魂が深く求めるもの・内なる欲求」を示す。名前の母音だけを抽出する理由は、母音が遮られることなく流れる息の振動＝魂の共鳴音とされるから。

## 背景・計算方法

ピタゴラス数秘術（Pythagorean Numerology）の体系に基づく。母音変換値:

| 母音 | 数値 |
|------|------|
| A    | 1    |
| E    | 5    |
| I    | 9    |
| O    | 6    |
| U    | 3    |
| Y    | 7（母音として機能するとき） |

**手順**:
1. フルネームをローマ字表記にする
2. 母音（A・I・U・E・O）だけを拾う
3. 数字に変換してすべて足す
4. 一桁（またはマスターナンバー 11/22/33）になるまで足し続ける

日本語名への適用例: RINKA → I(9) + A(1) = 10 → 1+0 = **ソウルナンバー1**

| 数字 | 欲求の核心 | キーワード |

| 1 | 自分の道を自分で切り拓く | 独立・自律・パイオニア |
| 2 | 深くつながり、共鳴する | 調和・協力・感受性 |
| 3 | 創造し、表現し、世界を明るくする | 喜び・芸術・コミュニケーション |

| 9 | 世界を癒し、人類に奉仕する | 普遍的愛・完成・解放 |

## 波動との繋がり

なぜソウルナンバーが「波動を上げる」のか——それは「知識」ではなく「自己認識」だから。自分の魂が求めているものを知ることで、長年の「満たされなさ」に初めて名前がつく。言語化されていない渇望は、意識の外でエネルギーを消耗させる。ソウルナンバーを通じてその渇望を「見る」ことで、エネルギーの流れが通い始める。これが波動上昇の仕組み。

## KEY POINTS
- ソウルナンバー ≠ ライフパス数。生年月日からではなく、名前の母音から算出する
- 母音は「息の振動」= 内側から流れる魂のエッセンス
- マスターナンバー（11・22・33）はそのまま使用し、一桁に還元しない
- 日本語名はローマ字表記に変換してから母音を抽出する
- 知ることで欲求が意識化され、エネルギーが通い始める
